# 平板原生零件图规则

版本：2026-10-20 / R1 标注规则、R2b.8 终态材料与原生加工表达。

> 2026-10-21 口径变更（用户确认以车间零件图为准；规划层已于 M3a/M3b 实施，含轮廓边到边成链，写图与读回尚未实施）：基准取包络极值边、不用内部局部基准；相切直段不要求直接标；3 段起合并 `n@p`；整数显示；允许对称两侧重复；螺栓孔用 Tekla 螺栓符号。见[规划层架构第 10 节](../../../docs/design/2026-10-21-native-planning-architecture.md)。下文 R2.1～R2.3 中与之冲突的条目仅描述现行代码行为，迁移到新规划层后废止。此文件是规则唯一维护源，项目设计文档链接到这里；安装版随 skill 同步。规则来自本项目用户确认的小平板试验，不代表任意平板已有通用执行器。

## 执行顺序：先定义加工表达，再选择标注

确定性规则负责“事实特征 → 必须表达的信息 → 覆盖核验”，调用 [加工表达引擎](expression-engine.md)。此层列出所有轮廓、孔、位置、大小和有来源的工艺要求；下一层才选择最少而完整的尺寸/说明与布局。多个特征可共用尺寸链，但必须逐项证明可确定。不得因为已画了中心线就把孔大小/定位当作完整，也不得把未知工艺、公差或局部加工面推测为默认要求。

## 1. 适用性与证据

适用于等厚平板，主面投影可完整表达直边、直线切角、已确定的圆弧过渡/缺口、贯通圆孔和长圆孔。通过最终实体核对平面性与厚度；不能仅由 ContourPlate/PolyBeam 类名断言是否平板。

折弯、曲面、型材、盲孔、坡口或无法确定的曲线不套用本规则。复杂多段折线平板即使共面，也须已有获认可的尺寸方案；目前复杂长板待样例。非适用特征不得删除后把剩余图当成完整图。

- 逐段轮廓、厚度、逐孔槽、附件、切割效果必须分别具备明确来源和充分证据，并检查完整性与矛盾；先列缺口，再决定是否需要 NC。原生参数与终态证据充分时不要求 NC。
- NC 是可选见证，按当前模型有效的精确零件编号关联：文件名、日志编号、ST 内部编号一致，同号多个实例可以共享 NC，不要求代表实例 GUID 与所读实例相同。保留 GUID 追溯，编号过期/错号/旧日志/数值矛盾仍检查，不用形状相似跨编号替代。KA 展开是该编号的有效加工信息，孔径/数量可读取；展开到原形的定位单独证明，不删除 KA 后直接比较原形。
- 区分 NC 不可用、对应算法未覆盖与明确几何矛盾。适用 NC 的数值矛盾须保留；缺少 NC 不能抹去孔作用、未知切割等原生缺口，NC 成功也不能独自填补这些缺口。`EVIDENCE_MATCHED` 只是诊断匹配，出图还需逐项充分性和版本重查。

- 编号严格等于 Tekla partPosition，保留标点；模型 ID 与图纸显示标记分别记录。同编号只有在几何、孔及加工特征一致时才能合图；冲突进入复核，不以形状相近替换编号。
- 原始轮廓、切割、倒角属性与最终实体互证。未改变实体的倒角不画、不标。任意 Chamfer.X/Y 不直接等于半径，须由可靠曲线或实体点验证。
- 收集所有作用于目标板的孔组，不以 Hole1～Hole5 全 false 或 Bolt=false 排除。Part.GetSolid() 无孔环只表示这条证据路径缺失，不单独证明没有建孔。
- Bolt=false表示仅开孔；Bolt=true组的实体可能是紧固件，不能当切孔体。仅开孔实体先在自身坐标系核验孔形/完整棱柱，再按模型长度预算核对投影到目标板的两端面与孔边界；微小轴偏斜不能只用固定角阈值误判。仅开孔体通过形状及目标两厚度面核验后可参与终态材料求解；原始诊断保留，不宣称取得目标孔壁BREP。
- `BOLT-THROUGH-01`：用户2026-10-20明确确认，确定作用于目标板的螺栓孔必然贯穿。Bolt=true且标准/孔参数/轴向/目标关联明确时，不再要求独立孔壁、剖面、CutLength或NC证明贯穿；仍逐块核对孔径、槽形、数量、位置和材料域。多目标特殊槽孔/扩孔的参数作用范围不明时不能把同一尺寸套给所有板，需补目标特定孔形。
- 独立孔观察是可选补充路径：提供时仍核查快照摘要、目标、数量、孔形及入口/出口，明确矛盾必须保留；缺少观察不阻断已由工程规则确认的贯穿孔。Drawing.Bolt/ModelIdentifier/SymbolContainsHole、人工圆、尺寸及中心线不能冒充独立孔壁读回，也不能替代最终孔清单与切割组合。
- `STUD-NO-HOLE-01`：用户2026-10-20明确确认，栓钉仅焊于表面，不形成孔。BoltStandard=STUD在孔公式前归类为表面附件，不进入孔数/孔径/孔定位，也不因缺孔壁阻断平板。保留附件来源，不据此宣称装配焊接要求已验收。其他未知附件仍不猜。
- r2b.8的`materialFinalState`统一求解全部已确认孔槽与Boolean切割。最终孔数、孔形和外边界由解析材料差集得出，包含的小孔不重复标注，相交孔按真实内轮廓表达；每个原始源保留贡献映射。仅在终态未解决时保留旧`finishedHoleCandidates`候选，不按原始孔组数量直接出图。
- 零尺寸 ROUNDING（X=Y=0）不生成圆角候选，终态轮廓仍需匹配。OVERSIZED 与 SLOT 分开解析：已支持Y=0的扩孔增量方式，不能因为SlottedHoleX非零就判为长槽。
- Boolean圆形切割须读切割体自身的建模圆弧、坐标系和实体，再检查目标投影、贯穿范围及两主面内环。多段弧不共圆时保留各弧参数与残差，不以显示精度或默认NC半径强行拟合为一个圆；未覆盖的操作交互继续保留缺证。
- 实例图保留所选实例双精度，按显示精度标注；同号代表NC不覆盖实例实测尺寸。人工确认某实例的尺寸解决该图取值，不自动取消通用NC差异检查，也不扩大到其他同号实例。
- 模型、零件局部和视图坐标要明确转换，验证轴向、手性和比例。保留真实坐标，以已记录容差识别共线/等距，不提前四舍五入制造等距。显示精度不等于几何容差。
- 本项目用户已明确模型几何核验采用0.1 mm（含）容差；`audit-native-geometry` 的CLI/API默认使用该值，并记录modelToleranceMm。共圆和边界核验中不超过此值的数值残差可接受，原始坐标、弧参数和残差继续保留。超预算、漏源/漏孔、拓扑歧义仍单独处理；这不是制造公差，也不把所有尺寸凑整或覆盖NC独立预算。

### 简单平板切割终态的可执行规则

- 对等厚ContourPlate及其贯穿BOOLEAN_CUT，读取全部切割体的独立轮廓、坐标系、实体和操作身份；在自身坐标系验证切割体，再核对目标投影与实际厚度覆盖。不能只凭CutLength或两面孔环宣称完成终态核验。
- 使用解析直线/圆弧计算最终材料边界，支持内圆孔、长圆孔、闭合切口、边缘缺口和多个切割的相交/包含/重合。最终必须为单块平板；全部原始操作保留贡献映射，无暴露边界的操作不等于遗漏。
- 上下主面必须分别同时包含完整外环和全部内环；所有边界与解析域唯一对应，再逐一核对内外侧壁、法向平面/材料朝向、面来源、上下对应和全部边覆盖。缺内壁、额外环、假圆盘面、错来源、盲切均未通过；重复端面不是多个孔。
- `materialFinalState=MATCHED`且逐项证据充分后，使用`finalOutline`和最终内环生成加工表达要求，不能继续标被切掉的原轮廓或简单累加切割体孔数。`cutFinalState`只代表Boolean范围，不能覆盖完整材料结论。原始`outline`和`planarCuts`继续保留追溯；终态圆孔/槽孔保留尺寸，其他切口保留解析线弧。
- 本层按模型预算核对终态，不声称取得精确BREP。优先匹配完整目标含孔实体；Tekla实体未暴露螺栓孔时，先核验完整Boolean终态壳，再按贯穿孔规则/仅开孔体证据统一计算最终材料。查看`materialFinalState.basis`与`finalHoleSurfaceObservation`，不把工程规则写成实际孔壁观察。未知操作、增材、明显斜切、坡口、分裂或边界歧义明确未解决。
- NC按需：纯切割圆孔/槽孔可与最终轮廓对账，已知矛盾不能忽略。原生证据已经充分时不强求NC；未支持的NC内轮廓或混合孔源对应明确另报，不能伪装匹配。逐特征SUFFICIENT之后仍要做写图前重查、表达覆盖和图面验收。

## 2. 视图与基本样式

- 主面视图显示真实轮廓及所有贯通孔，邻件不得干扰。遮挡或投影无法表达加工特征时进入待补方案，不能隐藏特征求简洁。
- 板内空白区只放精确零件号，无引线、无箭头、无边框；不重复规格和材质。此要求不自动删除既有标题栏/型材栏。厚度必须由已核对的型材栏或图纸信息明确表达，不能因不画侧视而漏掉厚度。
- 线性尺寸保留 Tekla 默认实心箭头，不叠加斜划线。当前试验字号 2.5、箭头 2×2、显示精度 0.1 mm；作为起点，按实际图纸可读性验证。
- 圆孔和长圆孔均画两条相交于真实中心的正交点划线；长圆孔中心线沿真实长短轴。长度按纸面可读性确定，不能让中心线盖住孔说明或造成假孔。

## 3. 外形、切角与圆弧

- 最外层为两个正交方向的总体尺寸，内层表达轮廓转折和孔位置。总体尺寸锚点取实际极值边/点，避免用圆角前的虚拟交点。
- 直线切角用两向投影尺寸或真实剩余直边及转折定位完整约束；不自动增加斜边长度、角度或虚构 C 值。各段尺寸必须能重建形状，不能仅有总长宽。
- 圆弧过渡和缺口用 `R=数值`，箭头落在实际可见弧段。弧的数量、所在角/边、相切关系及位置也须由实际轮廓和相邻尺寸确定，仅有半径不算完整。
- 禁止由半径标注补画完整辅助圆。必要时用原生文字引线实现半径表达，仍须绑定源圆弧证据。
- 普通尺寸锚点只取实际实体边、角点或孔心；本规则不启用未显式构造的理论交点。
- 缺角附近界线与实体留清晰间隙，不沿缺失材料补成假直角。缩短界线只改显示，不移动尺寸锚点、不改实测值。

## 4. 孔组说明与数量

同形、同尺寸、同加工语义且归属明确的孔可合并说明；不同孔形/尺寸/方向应分组，不能用一条含糊引线覆盖混合孔组。不同方向若分别定位并明确归属，可复用尺寸说明。拆分后核对组数量之和与全部实际孔数一致。

| 特征 | 写法 | 含义 |
|---|---|---|
| 圆孔 | `nΦd`，如 `2Φ26` | n 是孔数量，d 是成孔直径 |
| 长圆孔 | `n×D宽度(总长×宽度)`，如 `6×D22(81×22)` | 总长包含两端半圆；不是直段长度 |
| 连续等距 | `n@pitch`，如 `2@160` | n 是间隔段数；3 个中心只有 2 段 |

以实际成孔几何确认孔径和槽总长。对已核实的 Tekla 槽孔参数，可用“孔宽=公称直径+孔公差、总长=孔宽+长向增量”计算并与实体/原生孔显示交叉验证，不能对其他孔类型直接套公式。

每组引线指向一个代表孔的近侧可见孔壁，沿孔心朝文字方向取交点。圆孔交点为 `center + radius * normalize(text-center)`；长圆孔须与真实胶囊形边界求交，不与矩形包围框求交。引线不穿过孔内指远侧，不指孔中心或中心十字交点，不跨越其他孔排。不同区域无法无歧义归组时拆分并明确局部数量，避免重复计数。

## 5. 孔定位与等距链

- 每个孔必须有可追溯的两向定位；同排/同列可以共用坐标链，不能只标孔距而无基准边距。槽孔还必须有方向依据。
- 从实际基准直边到第一孔心，再逐孔心标间距。同排多个孔两端均有覆盖孔排的真实直边、排内无其他边界时，标完整两端边距；错列或对边为缺角/斜边时不强收链到虚拟交点。
- 两段及以上连续等距才组合为 `n@pitch`；仅属于孔中心之间的间隔参与该表达。离散的相等边距不得合并，边距恰好等于孔距时也须拆开尺寸集或禁用跨界组合。
- 等距组合只显示两端界线，文字居中；中间孔保留中心十字线和原生测量锚点，仍逐段读回间距与段数。不要让中间界线穿过组合文字；Tekla 2017中隐藏原生字体仍可能保留文字遮挡范围。
- 孔数与间隔数分别核验；错列、间距变化处断链，不把不同排拼成一条等距链。
- 界线从靠近尺寸线的孔排引出；孔定位层置于总尺寸内侧，避免无信息增益的重复封闭链。

## 6. 布局顺序与避让

1. 先取得图框、标题栏、表格、视图与可用纸面范围，确定主面方向、比例和板内编号空白区。
2. 分配内层外形转折/孔定位，外层总体尺寸；第一层距轮廓约 12 mm 纸面，平行层增约 10 mm 作为初始候选，非固定合格阈值。
3. 为孔说明和半径引注选邻近空白区，箭头锚点先固定在真实边界，再选文字侧向位置。允许移动文字、换侧、分层、调整比例/图幅，不移动几何取点去“凑”布局。
4. 用实际字体、文字旋转和原生渲染复核文字/箭头/线段/轮廓/中心线/表格间冲突。短尺寸可外置文字；禁止压字、重叠或把引线误读为实体。中心线穿过其所属孔、界线与所属尺寸相接是预期连接，不能当普通碰撞。
5. 检查全图及短边/圆弧/密孔局部。视图居中、包围框不交和对象数正确都不单独代表合格。无可行布局时明确标记待调整，不能删掉必要尺寸换取通过。

通用规划R2优先按外轮廓的连续单调特征建立尺寸链，不再对每个坐标从统一基准逐层拉线。相同坐标链共享表达；已有可信R与轴向端点关系时省去可推导切点，但缺R或位置约束仍必须失败。短肩部就近标，保留板身宽等便于加工的直接尺寸；相交区间才增加层距，总尺寸最外层。不能按固定尺寸组数或零件编号删标。

R2.2补充：包含孔链的板身宽也须在孔定位层外，不能因其不叫整板总尺寸就排到里面。与R相切的轴向直边须直接表达加工长度，不能按纸面长度门槛省略短直段；同坐标对称边可共享。短局部区间若能由轮廓邻接、相切及真实共享端点唯一确定为“直段+R投影”，优先直接标真实直段，避免让使用者做减法；不额外叠加被替换的综合投影。短尺寸只影响文字/箭头/界线排版，不能改变应表达的加工信息。R引线与短尺寸仍须避让，完整定位须通过独立覆盖门。

R2.3按用户确认的布局推广至所有轮廓区间：实际分段优先同列，圆角过渡处断开，总尺寸保留最外层。已有真实直段及相邻轴向R能完整证明综合跨度时，用直接直段替换“直段+R投影”，取消重复综合尺寸；不可仅凭数值相减或某处存在同半径圆弧删标。替换须有真实共享端点、包含关系和相邻圆弧端点投影证据，歧义或覆盖不足则保留/阻断。

同一轮廓尺寸链拆出的不连续分段，用独立原生尺寸集表达，按真实间隔放在同一列；不得在圆角区补不存在的直段、将间隔两端合成同一点或跨间隔连成连续尺寸链。布局避让时整列移动，不让各分段各自散开；孔定位仍在包含它的板身尺寸内，总尺寸最外。保存重开核对实际Distance/Up、锚点和值，验证同列和间隔确实保留。P-116的110、66、30同列且取消120是此通用规则的验收例，不是编号分支。

孔定位优先选跨度覆盖孔排的附近真实直边，近似等距时稳定选择；没有合适直边才保留原真实基准。孔说明优先板内材料空白区，文字框和近侧引线不得穿其他孔，再考虑四侧外置。编号仍选材料内空白区，圆形外轮廓用直径配同心位置证明。孔数量与间距段数各自核查。

缺角/肩部允许缩短显示界线，但原生尺寸锚点和值不变；真实界线在保存重开及DXF中独立核验。R与孔引线不得穿过尺寸线或自有界线，新增LEADER_CROSSES_DIMENSION门。必需文字放不下在PLAN阻断，不以覆盖完整掩盖缺对象；当前没有失败后自动重排循环。

## 7. 完整性和保存验收

从模型独立列出的特征清单逐项核查，而不是从已生成对象反推“没有漏标”：

| 检查对象 | 必须证明 |
|---|---|
| 板件 | 精确编号、轮廓全部段、总长宽、厚度、视向一致 |
| 切角/圆弧/缺口 | 形状、大小、位置、实际锚点，未补画不存在的边或圆 |
| 每个圆孔 | 实际数量与孔径、X/Y 定位、中心十字线、说明归属 |
| 每个长圆孔 | 数量、宽及总长、中心 X/Y、长轴方向、中心线、说明归属 |
| 尺寸/文字 | 保存重开后真实值与显示精度一致、样式正确、无多余旧标注 |
| 图面 | 清晰可读、无漏标/重叠/误导性交叉，图框表格与页面边界避让 |

几何证据不足标 BLOCKED；未做保存重读或图面检查标 PENDING；确定错误标 FAIL。只有全部所需证据通过才报告本图 PASS。本项目追求每张交付图完整准确，不把未经验证的图计为“100%准确”，也不承诺所有新类型均可自动完成。
