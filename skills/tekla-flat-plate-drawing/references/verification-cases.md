## 修改规则或适配器时应演练的决策

| 输入/失败条件 | 正确处理与可观察证据 |
|---|---|
| 三孔等距 160，或六槽分成两列三排 | 孔数写 3 或 6；纵链为 2@160，行列与总孔数分别核对 |
| 两端边距与孔距恰好同为 160 | 仍保持边距独立，仅孔间段组合；检查原生渲染未跨边界组合 |
| 混合 Φ22、Φ30、22×81 及旋转槽 | 分组数量相加等于真实孔数；分别说明和两向定位，旋转槽方向明确 |
| Hole1～5 为 false、Bolt=false，原生图显示孔 | 联查作用关系/组几何，不能丢弃；证据冲突标 BLOCKED |
| 同号其他实例的 GUID 出现在本次 NC 日志 | 编号最新、文件/日志/ST 同号时接受为该编号的代表 NC，GUID 保留追溯，不再按异实例拒绝 |
| 同号展开 NC 含两个 IK，每个两段 R15 | 孔清单为 2Φ30；展开范围有效，原形孔定位须另证，不能当 Φ15 或只看 BO 漏孔 |
| Part.GetSolid 无孔环，但孔组可能作用于板 | 不能生成“无孔”结论；确认目标螺栓孔按BOLT-THROUGH-01处理，仅开孔体核验自身形状与目标厚度面；符号和文字不是孔壁观察 |
| Bolt=true、多目标且目标孔的独立几何齐全 | 逐目标核验，孔可 COMPOSITE_CONFIRMED；不把紧固件实体当切孔体，不放行整件 |
| 观察缺失、旧摘要、错目标、重复、孔径/方向/贯穿不符 | 未提供可选观察不阻断已满足工程规则的孔；提供时缺证保留、非法来源拒绝、明确矛盾为CONFLICT，不能由旧实体MATCHED掩盖 |
| 半径引注读回正确，但显示整圆 | 图面 FAIL，改成实际弧段引注并重验；不能用 API PASS 覆盖 |
| 圆角前虚拟交点让孔链多出 65 | 删除无依据端点，恢复真实基准到孔心的完整定位；不任意改尺寸值 |
| 孔说明线穿孔指向远侧 | 改为朝文字近侧孔壁，中心十字线仍完整 |
| 有 8 组中心十字但仅有槽孔说明 | 对圆孔的大小和定位覆盖仍 FAIL，不按中心线数量判全标 |
| 同编号不同孔型，或模型变更后旧图仍可打开 | 阻断合图；源指纹失效，重新读取和验收，不能沿用旧 PASS |
| 重跑已有试验图，其中有人工 Text/Line | 只替换拥有标识的对象，人工对象保留；重复运行不增加自有标注数量 |
| 表格压字、字体包围框未知或无可用原生预览 | 图面 FAIL 或 VISUAL_PENDING，不能靠视图居中判通过 |
| 多选中混有复杂件/坡口/盲孔 | 每件独立状态；继续其他已授权适用件，明确列出阻断件 |
