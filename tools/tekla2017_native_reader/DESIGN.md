# 原生读取器设计

## 目标与方案

为原生出图提供独立原始证据，避免旧导出器提前把端点连线、面法向、孔参数当成已证明制造几何。旧问题见 保真审计。选择新建 SDK 读取程序；旧导出器和离线流程保持独立。

SDK → teklaNativeEvidence.v1 → Python nativePartFacts.v1 → R2 几何证明 → 加工表达要求 → 原生标注。R1 实现前两层，R2a 增补来源一致性和独立 NC 见证审计；R2b 已实现有限类型解析候选及可用证据对账，精确成品证明仍有缺口。见 路线。

## 数据契约与关键决策

2026-10-26 r2b.12（Python审计，读取器不变）：通用挤出壳核验移到 `solid_prisms.py`；`geometric_types.py`先收集完整截面/双面/方向事实，再纯事实分类，最后调度专用几何证明。runtimeType只解释API轮廓字段的语义，不决定形态；PL规格仅在后续作一致性核验。识别的折弯形态不推断制造工艺，未知曲面不拟合猜测。见[类型分层设计](../../docs/design/2026-10-26-geometric-part-types.md)。

2026-10-26 r2b.11：特殊槽孔螺栓组新增当前板/硬件实体的逐轴有限线段交点。查询段来自硬件包络沿真实轴向的投影，保留原始重复交点；几何层配对并合并相接材料区间，要求连续区间跨越已证明的板厚两面。连接数量不作为拒绝条件，Hole标志不按关联列表顺序分配。逐板孔形由独立精确编号NC的全部孔唯一对应补足，实际配置绑定仍UNCONFIRMED；见[设计](../../docs/design/2026-10-26-target-hole-penetration.md)。

2026-10-26 r2b.9：读取目标与 Boolean 操作体的 RAW 实体，保留操作体 ID。几何层为非 ContourPlate 增加普通直边/完整平面挤出壳通道；类型只决定建模轮廓的语义，不决定是否为平板。平行双面、薄向唯一性、RAW/NORMAL 厚度域、全部面边和操作贡献必须一致。CutPlane 以最终实体确认保留侧后解析贯穿半平面裁切，仍由完整最终壳独立核验；不把 RAW 当最终实体，不重用 PolyBeam 路径作为板边界。新框架若与 DSTV 不一致，NC 对应标记待验证。见[设计](../../docs/design/2026-10-26-modeling-independent-flat-plate.md)。

属性/集合状态为 READ、UNAVAILABLE、ERROR。READ 表示 API 返回值，UNAVAILABLE 表示 API/读取器未提供，ERROR 保留异常及已读部分；不补成 0、LINE、ROUND、PLANE。原始枚举顺序和重复值保留。Contour 外层异常保护与内层集合状态分别保留。

Python 输出保留逐件 rawEvidence 副本和指向原始文件的 JSON 指针 sourceRef；API source 文本只是来源标签。rawDigest 是按键排序、无额外数值舍入的 JSON SHA256；rawFileSha256 是文件字节摘要。读取时间参与前者，重复读取稳定性比较单独排除时间字段；摘要不假充模型版本锁。

DIRECT 表示原始读取值，不是几何 PROVEN；DERIVED 表示公式/候选；UNKNOWN 表示无依据。实体目录不将 EDGE_TYPE_NORMAL 翻译为解析直线，不将法向翻译为平面。环顶点与边端点按完整数值精确匹配：唯一也仅为 CANDIDATE，零/多个为 UNKNOWN，绝不去重。容差与拓扑证明留给 R2。

孔组保存全部语义。标准恰为 STUD 时分类提示 ATTACHMENT_STUD，不生成钻孔参数；其他非空标准为 HOLE_CANDIDATE。BoltSize+Tolerance 及加 slot 增量只为参数候选，不证明孔形、轴向、开关对具体板的作用或贯通；组位置计数不等于已证明实际孔数。未知标准/缺参数不默认圆孔。Boolean、Fitting、CutPlane 保存源操作，最终效应尚未证明。

## 错误处理

递归检查状态，顶层 COMPLETE 不覆盖内部 ERROR；缺必需字段、无模型身份、选择解析不一致、平面恢复未确认降为 PARTIAL。拒绝非有限数及非法 schema/坐标空间；不覆盖输入或已有结果。采集 COMPLETE 可同时有 API_UNAVAILABLE，含义为当前读取器能力内完成，不表示全部事实齐备。

普通读取查询明确 ID 或当前选择，不自动找相似件，不改变选择。工作平面暂时切换及恢复；显式 NC 采集另需临时选择与恢复。没有实体写入、CommitChanges、图纸 API 或鼠标键盘控制。读取不是事务快照，前后身份/时间/完整原始字段比较也不能排除两次读取之间改后复原，R2b/R3 仍需逐特征对账与写图前重读校验。

## R2a 见证契约与边界

官方 NC 是按需使用的独立见证，公开实体接口缺解析曲线时可参考其符号半径和孔槽块，但只能给量化后的导出字段。完整证据包以原字节及摘要绑定文件，NC 保留原块、行号、十进制字面值、修饰符和分辨率；不拟合圆弧、不把 BO 定位字段解释成孔中心。解析器只识别当前已验证的板件 ST/AK/IK/BO/KA 格式；未知格式限制该见证，KA NC 不适用于原形，不直接否定目标原生几何。

每次采集保留累计日志前缀，只对新增字节核对 GUID/编号/文件/模板。前缀被替换或读取失败时阻断，不猜测新日志边界。前后模型、零件全量字段、编号、选择、时间窗口及文件摘要分别检查；当前 r2b.4 以精确编号归属加工 NC，允许同号代表实例共享文件；GUID 保留追溯，不宣称实例相同。配置文件前后摘要仅证明观察文件未变，API 实际配置绑定始终 UNCONFIRMED。CANDIDATE 只是进入后续证明的候选，制造状态始终 BLOCKED。

输入文件内容仅按 JSON/文本解析，不执行其中命令或按 NC 名称访问磁盘；输出不覆盖已有证据。SHA256 用于内容关联及误改检测，不是签名或对恶意伪造来源的认证。完整证据包包含现场路径/数据，仅存忽略的 outputs。捕获失败保留已有诊断文件并退出非零，不复用旧成功结果。详细规格见 来源策略。

## 当前材料与表达契约

r2b.8将所有已确认孔槽与Boolean切割统一求解析差集，完整目标壳可实读时逐面边匹配；Part.GetSolid完全省略孔组孔时，先匹配完整Boolean壳，再采用用户确认的BOLT-THROUGH-01或仅开孔体形状/板厚证据。部分孔壁、多余孔、未知子对象和显式矛盾不能通过该回退。STUD按STUD-NO-HOLE-01只保留附件来源。多目标特殊孔形归属不明仍阻断。

原生表达入口直接从完整材料结果生成要求并绑定摘要、规则版本和预算，不制造旧VERIFIED上下文。混选非Part是选择范围信息，不是坏Part；显式错误ID仍报错。理由、适用范围与反例见本轮设计。

## 历史检查与已知限制

下列r2b.4孔作用强制观察和包含/重复阻断记录由r2b.8完整材料规则覆盖；精确曲面、未知类型和生产写图限制继续保留。

R2b.4 消费纯原生证据或完整 capture，不接外部声明的 PASS。目标身份/版本/读取一致性由 `geometry_evidence.native_sources` 独立核查；NC 来源在比较前按有效精确编号核查；同号代表实例接受，KA 展开保留加工信息，展开位置到原形的对应单独检查。模型候选来自轮廓与孔组参数，在 DSTV 正交单位坐标系中解析；模型原始值不舍入。实体面环投影验证两厚度层、双面边界、全部侧面挤出、边/面双向覆盖。适用 NC 逐段、逐孔唯一对应，未知参考语义/分段方式标对应未解决，明确数值矛盾单独标 CONFLICT。孔与外边界相交、自交、孔重叠/包含和重复候选均阻断。空操作集可记录 EMPTY_SET；非空操作/子对象需要独立终态证明，不自动忽略。

逐特征清单覆盖轮廓段、厚度、孔槽/附件、孔清单、拓扑与操作。字段包括 sourceRefs、evidenceStatus、proofStatus、missingProofs、ncEvidence/ncRole；`evidenceSufficiency` 聚合 SUFFICIENT/INSUFFICIENT/CONFLICT。参数匹配不补足精确面或实际含孔终态，NC 设置绑定只属于所用见证。见 技术方案。

`Bolt=true` 或多个目标时仍保留孔参数候选，但不把紧固件实体当作切孔证据。孔模式 GetSolid 与完整含孔成品实体的差别仍是剩余证明项。数值预算只表示对账条件；EVIDENCE_MATCHED 不是 PROVEN。详细算法、适用范围和退出码见 R2b 规格。未增加第三方几何内核；当前输入没有可供内核恢复精确曲面语义的可靠 BREP。

- SDK GetSolid 的边/面可能为内核离散表示，未取得精确圆心、半径、弧域和 surface class。保持返回值不能保证它们是精确解析几何。
- Part.GetSolid 未见孔环不能推出无孔；Bolt.GetSolid(true) 保留为独立组实体，作用与最终孔形需另证。
- 已完成有限类型厚度层/边界/孔槽方向的证据检查，但没有精确面语义、含孔成品实体以及任意操作效果证明；高级工艺/未知子对象保留原类型或缺口。
- R1/R2a 一律制造 BLOCKED，未接旧 snapshot 或表达引擎 VERIFIED 上下文；没有写图和视觉验收。
