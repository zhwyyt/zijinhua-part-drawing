## 所有权与副作用

主要防护对象是错误模型、错误实例和覆盖用户图纸。输入job属于可信本地流水线，不是任意远端提交接口；底层exe不独立重算Python的几何准入。不得向不可信用户暴露直接写job的能力。

图纸同时匹配名称NATIVE-PLATE-R1和目标ID，已有图还需已核查ownedSheet。写入前完整预检标注所有权与冻结/下发/锁定状态；不采用“名字相似就可覆盖”。最终实现不遍历总目录：新登记只尝试 Insert 第1页，碰撞即失败；已有登记必须带实际数据库身份，定向 Select 后再次核对实例/页号，同编号不同实例不混用。仅改专用图纸，不改模型，并恢复工作平面。M4 在切换工作平面前拒绝任何活动图纸，要求用户自行保存关闭；不替用户保存或丢弃编辑。

写图不是原子事务：SDK中途失败可留下部分自有试验图，但状态为FAIL，不作合格交付。M4 在 Insert 后立即保存身份收据，Python 即使准备失败也登记为 INCOMPLETE；不自动接管未标记标注，需按精确创建证据恢复，不能删除/接管未知图。日志和旧批次目录保留，不覆盖失败证据。尚无并发写图锁，同模型只运行一个批次。

## 图形和验收

直边无Boolean件使用模型Part轮廓；圆弧或Boolean件以原生Line/Arc/Circle表达已证明最终边界。r2b.11保留目标Part参与材料表（不Hide），只关闭其可见/隐藏线、填充及辅助显示；保存后逐属性检查。旧Hide方式使材料表数据行消失，已由现场失败证据复现修复，不放宽模板签名检查。孔符号隐藏并由终态孔形表达，已匹配实体孔边界不重复绘制。自定义文字和曲线必须随源变化重新生成，不宣称天然关联更新。

SDK读实际尺寸端点、文字、样式、对象位置和中心线；DXF提供可见曲线、文字字形与纸面证据。独立覆盖核验尺寸、孔数/孔形/两向位置、R/直径、中心十字线、厚度、零件号；图面核查纸内安全范围、文字重叠、穿字线。默认模板和中文预览字体未完成车间验收，不以自动PASS替代生产审签。失败返回，不自动无限重试。

## P6 显示口径（2026-10-21，现场未验证）

螺栓组只有在每个孔位都恰好对应一个、且只由该孔位形成的最终圆孔时，才显示为 Tekla 螺栓符号（Symbol2，含孔和轴）。被切割吞并、长圆孔或来源混杂的组仍隐藏，由终态孔形曲线表达，避免符号画出已不存在的孔。等距合并、取整和半径尺寸交给 Tekla 原生对象，读回按计划预测的合并段、DXF 文字和半径尺寸点独立核对。

## M4 模板边界（2026-10-23）

通过公开 PresentationModel 读取当前目标图纸的纸面层，排除模型视图；不按固定 Segment ID/类型号猜表格。归一化记录内外框、实际边线和保守文字带，P4 计算可用区。写前和保存重开后核对实际模板指纹，实际视图框必须落在可用区内。快照哈希用于本地证据一致性，不是对不可信 job 的签名认证。当前模板字体仍未作精确字形量测，未知图元和无法识别的框阻断。详见[M4设计](../../docs/design/2026-10-23-m4-live-template-snapshot.md)。

按登记身份定位用到 Tekla 2017 内部 Identifier/DrawingIdentifier 内存句柄字段，隔离在 TargetDrawingLookup.cs，只调用公开 Select 读取；真实写入前继续核对全部所有权条件。字段不可用或旧登记缺 ID 时阻断，不降级总目录扫描。当前版本跨进程定位与重复运行已在本轮验收。
