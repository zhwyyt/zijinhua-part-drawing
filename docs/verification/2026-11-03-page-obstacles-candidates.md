## 全页核验

每页重新核对capture、原语/字形报告及PDF摘要，解析绘制顺序。全页字形包络、遮罩、黑色原始/可见路径进入STRtree；路径和遮罩按实测索引/范围唯一归属到待移动原语。曲线使用控制点及实际CTM/笔宽/miter的保守边界，不可界定对象保持缺口。候选检查使用原始几何，避免移走旧文字遮罩后漏出未检查的线。

六页回放重现上轮反例：A2三个折引线碰自身字形包络；B2/20尺寸箭头约76.60%、直引线箭头约99.88%被遮；B2/50直引线箭头约99.98%被遮，折引线碰其他说明和编号，尺寸线碰其他文字。B2/50尺寸箭头约8.0005%的轻微削边仅通过`primitiveDigest/key/pdfPath/removedAreaFraction`绑定到这一具体接受记录，不将8%当通用门。严重遮蔽、穿字及其他冲突继续列明。

B2/10的目标原语未发现本轮检查范围内冲突，但每页保留92个既有表格缺字记录，所以它仍为INPUT_BLOCKED；其余五页为GEOMETRY_CONFLICT。没有用“目标原语没碰字”隐藏全页字体缺口，也不将缺字解决列为本轮额外工作。

四个实际几何反例已存入`tests/fixtures/part_drawing/independent-obstacles/real-counterexamples.json`，含原PDF/原语摘要及路径/字形索引，回归严重遮挡、已接受轻微削边和跨对象碰字。案例身份只用于证据追溯，不进入通用判断分支。

## 候选结果

每页两个已测引线、每个9种显式文字平移和4种路线，共72个候选；六页432个。测试偏移为横向−32/0/32字高、纵向−8/0/8字高，三条水平通道由本页实测尖端/端点高度构造。净距0.02字高是本次明确输入，不是生产角色阈值。位置、字符、字号、原锚点及实测箭头方向均保留约束，不按584编号写坐标。

| 证据页 | 直引线已知几何无冲突 | 折引线已知几何无冲突 | 有限池结果 |
|---|---:|---:|---|
| A2 / 10 | 16 | 0 | FINITE_POOL_BLOCKED |
| A2 / 20 | 0 | 0 | FINITE_POOL_BLOCKED |
| A2 / 50 | 0 | 0 | FINITE_POOL_BLOCKED |
| B2 / 10 | 17 | 0 | FINITE_POOL_BLOCKED |
| B2 / 20 | 0 | 0 | FINITE_POOL_BLOCKED |
| B2 / 50 | 0 | 0 | FINITE_POOL_BLOCKED |

33个KNOWN_GEOMETRY_CLEAR候选仅避开了已知障碍；仍有全页字体缺口，且必须原生写图/保存重开证明。没有任何一页被声明为共同可行。各候选报告保留具体阻挡ID、文字位移、完整路线和排序代价；生成器不贪心选定一个对象后忽略其他对象，候选间成对冲突接口已有合成回归，本组没有两个角色同时可用，成对可用集合为空。

失败主要来自固定尺寸界线形成的阻挡，以及原锚点附近编号/遮罩。首版保守禁止跨固定黑线，尚未细分尺寸线/界线的可交叉角色；所以该有限池失败不等于整个零件无解，也不证明必须换图幅。它说明下一步要把尺寸组与可移动编号纳入共同候选，并建立角色连接/交叉规则，不能只继续扩大引线偏移。

两种合法连接单独校验：原锚点只允许与实际绑定轮廓在局部笔宽/数值邻域连接，后续折线不免检；文字端只保留实际端点与自身遮罩的终段连接间隔，仍禁止碰真实墨迹/穿遮罩。反例覆盖无关线靠近锚点、后续重新穿轮廓、文字末段碰墨迹。几何预览`candidate-preview.png`仅画包络和路线，明确不是原生图面。
