## 净距及遮挡反例

本地`analyze.py`重放全页黑白路径，检查目标逐字墨迹外接框与可见线/箭头、其他字形框，以及目标可见原语与其他文字。未支持曲线以控制点包围框加含CTM/笔宽/miter的保守范围排除；六页目标附近无未排除的未知路径。该有限检查不提供生产角色阈值、精确字形布尔碰撞或全页全对象验收；原表格字体替代/缺字仍在。

1. A2三个折线引线末段进入自身首字包络（PDF路径11/11/10）。1200 DPI局部没有明显穿过笔画，但保守净距不能放行。B2依实际保存端点偏移，从左侧水平接入，三规格不再碰自身文字包络，箭头完整。偏移仅用于本组样本，没有写成按零件号或字符串的生产规则。
2. B2/10的四个目标原语在本次全页路径与文字检查中无相交、无遮箭头、无越界。
3. B2/20的159.9尺寸一个箭头损失约76.60%（路径23，白遮罩24/73），路径21完全隐藏；直引线箭头损失约99.88%（路径31，遮罩32），引线路径8/31与既有编号中字符8的外接框相交（glyph18）。这不是轻微削边。
4. B2/50的159.9尺寸一个箭头削边约8.0005%，该外观本身已接受；但路径84与既有字符6包络相交（glyph30）。直引线箭头损失约99.98%（路径14，遮罩15）。折引线的路径9穿过直引线文字“廓”和既有编号“4”的包络（glyph1/14），1200 DPI图可见文字旁伸出的线；因此“折引线不碰自身文字”仍不足以放行。

上述新反例归为**特征缺失：尚未接通全页障碍与候选避让**，不是源数据/锚点错误，也不靠继续缩字、移用假锚点或按584写死位置处理。后续应把既有文字、遮罩、尺寸与目标引线作为相互障碍，并将这些证据转成可重复的验收反例。`a2/summary.json`、`b2/summary.json`记录相交对象/路径及完全隐藏项；`*-visible.json`保存面积和遮罩索引，`*-ink.json`保存字形/字体证据；`whole-pages.png`和`crop-*.png`为原生PDF渲染。
