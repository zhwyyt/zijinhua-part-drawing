# 独立布局：首张完整原生试验图

用户授权先做一张可看的图。此次沿用已准入 584 实例，但实现按完整表达和实际几何工作，不按编号、固定坐标或固定尺寸条数分支。旧入口和已验收页不改。

## 边界与执行

1. 重新读取模型，重审 SOURCE_READY 和完整表达。首切片只支持单主视图、无孔、全直边外轮廓；不支持的表达明确拒绝，不删项。
2. 使用已核验的零件图10独立属性副本。图框实际尺寸 2980×2110；绘图区避开底部表格。按 1、2、2.5、5、10、20、50 逐级求解，首次可行即选。
3. 整组轴向尺寸在完整轮廓外生成不同侧/层候选，保留真实点、投影轴、显示精度和所有短间隔。总体在同侧分段之外。编号生成材料内空白候选。读取实际字体文件的字符映射与字宽，增加保守余量预测占用；预测不是实际墨迹验收。写入后再用已有嵌入字形轮廓适配器逐条绑定并测量实际墨迹。
4. CP-SAT 共同选择所有尺寸组和编号，约束文字与其他文字/线/轮廓避让、图幅、层次及完整覆盖。原生关联界线允许穿过其测量对象；禁止穿过其他文字。有限候选无解则换比例，不借旧 P5 布局。
5. 扩展独立试验执行器的显式 completeLayout 模式：一次只新建一页、立刻登记所有权。仅清除该次刚插入页的自动尺寸和目标零件标记，记录删除对象身份；遇额外未知标注拒绝。插入完整尺寸组和纯编号，固定视图比例及位置。
6. 保存、两次重开，独立核对每组真实锚点、轴向、值、文字、视图及持久性；从实际 PDF 检查完整图面。最多三次新建尝试，每次保留证据和登记，不覆盖先前页。

## 验收与限制

本次目标是交付一张完整原生预览图及实际图片，而不是宣告通用布局系统或正式入口已发布。必须包含本例六组共16个尺寸区间、精确编号和可读板厚。3 的短尺寸不得省略。已有轻微箭头削边按用户接受口径保留。

实现验证包括：缺少/新增未支持语义拒绝、非整数原始投影值保留、总尺寸在外、材料内编号、候选联合互斥和确定性、保存重开实际数值与模型点对应。模型/原属性/原台账 parts 和既有测试页记录前后不变。PDF 字体或表格遗留问题按实际图面单独记录，不能用预测占用冒充图面 PASS。
