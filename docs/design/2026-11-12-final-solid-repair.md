# 最终实体独立包修正

沿用 2026-11-11 已确认方案。本次修复实现，不改变试验目的，不接正式入口，不修改旧生产代码。

## 实现边界

1. 最终实体提供面、环、边和连接关系；读取失败、非有限数、退化/重复面、缺面缺边、错误法向及不闭合都不能标为 READY。保留每个来源面，合并共面区域须保留映射，不以最大面代表全部材料。
2. 在完整实体上测量并解释平板/尖角折板：面对关系和局部材料区域决定事实，建模命令不参加判定。声明厚度仅诊断冲突或消除几何解释歧义。保留未解释事实和具体缺口。
3. 孔和圆弧沿用已有证据口径。螺栓通孔需目标归属、形状、轴线与局部材料域核验；焊钉不是孔；孔-only 不凭参数放行。圆弧仅使用解析参数或已确认切割来源及误差核验。普通建模历史不得成为准入条件。
4. 平板适配已有纯表达构造函数，保留轮廓、孔槽、圆弧、坡口/剖面责任；不调用旧 audit、分类或切割重演求最终答案。折板记录段、折角/折向、端切、孔所属段及中面展开；制造展开口径未定须单独报告。
5. 分开记录实体完整性、特征解释和表达状态；几何 READY 必须代表声明范围内完整核验。对照报告从实际 JSON 生成，不手写状态表。

## 单向依赖

允许只读复用 `analytic_geometry` 的向量/线弧/轮廓数学、`planar_cut_region` 的二维边界运算、`native_expressions._facts` 与 `expression_requirements` 的纯表达构造、`section_plan.section_requirements` 的纯剖面表达。孔参数与圆弧来源辅助只在列明用途后使用；禁止调用旧整体几何审计、旧分类和旧材料重演函数。旧模块不导入新包。
