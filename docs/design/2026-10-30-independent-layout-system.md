# 独立零件图布局系统技术方案与实施计划

更新时间：2026-10-31

状态：设计修订版，已纳入零件图10/20/50的源图采样及20/50候选属性证据；模板选择以图形大小合理、标注清晰为前提。阶段0已开始独立实现，来源封装、模板研究解析和最小几何验证可离线运行；加载、单位、样式与稳定性验证未完成，未替换现有布局

本次修订只补齐设计。新布局求解器独立重做，不修改原求解器、原尺寸方案、原几何规则或正式入口。后文的实现和现场验证均为未来开发任务，不代表已经执行或取得现场写图授权。历史评审建议以本方案的采纳结果为准。

## 1. 目标与边界

本方案为 Tekla 2017 原生平直板零件图设计一个独立的布局系统。系统接收已经核验的几何事实和已经确定的加工表达要求，决定尺寸链、孔说明、半径说明、零件号和其他图面对象的纸面位置，并输出可供 Tekla 写图的布局计划。

布局系统不重新识别几何，不从图面反推加工事实，不决定“应该标什么”。这些责任仍由几何事实、特征核验和表达要求模块承担。布局系统只解决以下问题：

- 哪些合法候选位置共同组成一张可读图；
- 尺寸链、孔带、说明和引线如何互相让位；
- 如何保持同列、内外层、总体尺寸和孔组语义；
- 如何在模板和比例约束下找到最好的可行解；
- 如果当前候选集合无解，如何报告具体对象、冲突和缺失候选。

首个发布范围只覆盖平直板单主视图以及 Tekla 自定义零件图10、零件图20、零件图50 三种规格。交付验收对象为 Tekla 原生源图，不包含后续 CAD 排版或打印成品。准入集合在求解前按事实充分性、表达要求 READY、FLAT_PLATE 和仅需主视图冻结，不能以“能否布局成功”作为准入条件。折弯板、曲面板、折梁、展开图和需要剖面等新增视图的零件不在首版范围，记录排除原因，不能删除其额外视图要求后纳入。

最终目标是冻结准入回归集 100% 产出通过表达覆盖、独立图面验证、Tekla 保存重开和源状态复核的图纸。准入后发生候选不足、图幅不足、超时、原生能力不足或缺证，均留在分母中，计为未通过并建立缺陷。这个目标不是任意平板在有限图幅和固定字号下必然有解的数学承诺；准入回归集仍有失败时不得宣告达到发布门。

## 2. 设计结论

不继续扩展现有按顺序放置的 `construct_layout`。新系统采用独立的“候选生成—硬约束求解—受控空间放宽—软目标优化—原生回读校正”架构。语义不放宽；允许的空间放宽必须作为事先定义的候选类型记录在计划中，不能由求解器临场改变规则。

开源项目按职责借鉴：

| 项目 | 采用的思想 | 本项目中的位置 |
|---|---|---|
| QGIS PAL | 为每个特征生成候选位置，建立候选冲突关系，再做全局选择 | 候选模型和冲突图的主要参考；不直接复制代码 |
| OR-Tools CP-SAT | 处理“每组选择一个、冲突候选互斥、层序和模板边界”等离散约束 | 首版离散求解后端，在实施阶段 2 接通，Apache-2.0 |
| Dymo | 用全局评分改善一组标签，而不是逐个贪心放置 | 首版之外的可选质量优化参考；不负责必需标注完整性 |
| Adaptagrams/libvpsc | 带分离约束的连续位置调整 | 连续微调的参考，必要时再接入 |
| Adaptagrams/libavoid | 引线避障和折线/正交路径 | 仅用于复杂引线路径候选或后处理；不决定标注语义 |
| cad-agent | 声明式工程图对象、空间索引、生成后校验和预览 | 对象契约和验证流程参考；其逐圈试放算法不作为核心 |

PAL 的实现许可为 GPL，Adaptagrams 为 LGPL-2.1-or-later。第一阶段只借鉴公开算法和数据组织，不复制受限源码；代码依赖仍优先选择 OR-Tools Apache-2.0、Shapely 和现有项目依赖。若以后直接链接 Adaptagrams，另行做许可证和构建评估。

### 2.1 评审建议的处置

2026-10-30 的评审意见已经逐条复核。以下建议纳入本方案：

- 阶段 0 先做 Tekla 原语可控性矩阵、文字占用标定和单主视图合格输入（当前选584）的写图—保存重开—回读纵向切片；
- 生成器和验证器使用不同的纸面图元入口，验证器不复用候选生成器的碰撞函数；
- 候选池分级只增加合法候选，不临场改变语义规则；候选不足、静态阻断和对象互冲分别报告；
- 对同一对象做可证明的候选支配剪枝，对完整约束关联图按连通分量分解；`columnGroup` 的组级 Pareto 配置保留外部冲突关系，按 §5.4.1 执行；
- CP-SAT 的长度、坐标和代价使用固定精度整数化，固定 OR-Tools 版本并记录确定性配置；
- 回读差异最多进行有限轮次的候选禁配或占用校准，不能无限重试；
- 人工图和 A/B 偏好用于校准软目标，纯 Python 小规模穷举作为测试预言机，不作为生产后备。

以下建议暂不纳入或已按用户口径收紧：

- 图框限定为用户指定的零件图10/20/50；先选模板，再在该模板内按比例序列重新生成候选和求解。1:1 只是视图比例候选，模板名称中的数字不是比例分母；不临场扩大图框或隐式续页；
- 加工语义保持硬约束，只允许本方案明确的零件号近旁外置和孔组引线/折线外置；孔说明锚点按 §3.3.1 区分孔源；不自动允许界线穿无关孔或其他会改变读图语义的放宽；
- R2-C 只做诊断和温启动，不作为生产兜底；
- READY 平直板准入范围最终目标为 100%，但失败必须留下缺陷和最小复现输入，不能通过缩小准入范围消除失败。

## 3. 当前可用输入条件

布局系统的输入必须来自同一个模型、同一个零件实例和同一次事实快照。所有输入都要带来源摘要，禁止把不同读取时间、不同零件实例或不同坐标系的对象拼在一起。

### 3.1 零件事实快照

当前正式原生路线的输入来自原生读取证据、`audit_native_geometry` 和 `build_native_expression_requirements`。`PartDrawingSnapshot` 是另一条已有快照契约，不可与原生路线字段混用。首版只接原生路线；如以后支持 `PartDrawingSnapshot`，须增加独立、带版本的输入适配器和等价性测试。

| 输入 | 当前原生来源 | 布局用途 |
|---|---|---|
| 身份 | requirements.source 的 modelIdentifier、partId、partPosition；raw_part 的 id、guid | 防止串件；不能以编号代替实例身份 |
| 形态 | geometry.partType.route / requirements.partType | 仅准入 FLAT_PLATE 单主视图 |
| 材料 | 原生属性的状态和值、已核验厚度、requirements.specifications | 只表达有来源的标题/加工信息，不猜数量或材质 |
| 坐标系 | geometry.frame、raw_part 的源坐标系 | 保留已核验主平面；不重新选择几何基准 |
| 轮廓 | requirements.facts.segments、points、boundaryLoops | 保留有序边、弧和边界归属 |
| 孔 | facts.holes、points、groups、sourceFeatureRefs | 孔源、孔形、中心、组语义和来源绑定 |
| 终态 | geometry.materialFinalState、geometryStatus、evidenceSufficiency | 证明输入已经通过上游质量门 |
| 操作证据 | 原始操作、源引用和审计摘要 | 追溯使用，不在布局阶段重新解释 |
| 质量问题 | requirements.issues、geometry 的阻断原因和 remainingProofs | 缺证或矛盾不得进入布局 |

圆孔/槽孔为 ROUND/SLOT；其他已证明的闭合切口可能以 boundaryLoops 和线弧段表达，不能丢弃。阶段 0 逐类型检查新适配器是否完整承接；缺类型属于契约/候选能力缺口，不能重新解释为“上游未证明”来缩小准入集合。ID 至少在同一冻结输入内稳定唯一；跨快照 pin 必须重新核对来源，不假定枚举编号永久稳定。

### 3.2 加工表达要求

原生表达要求计划是布局的必需输入。必须满足：

- `status == READY`；
- `source` 与零件快照的模型、`partId`、`partPosition` 一致；
- `source.nativeInputDigest` 对应原生审计输入，`sourceDigest` 原样保留为表达来源摘要；二者含义不同，不做相等比较。新增 `requirementsDigest` 对完整冻结要求计划计算，用于检测内容变化；
- `modelToleranceMm` 和证据状态有效；
- 每条 requirement 有稳定 ID、类型、来源特征和覆盖要求。

要求计划目前表达以下内容：

- 轮廓分段、总长总宽、切角和圆弧；
- 每个孔或孔组的形状、数量、尺寸和两向定位；
- 槽孔长轴方向；
- 半径和圆弧位置；
- 厚度、规格、零件号等图面文字；
- 必须覆盖的形状、尺寸、方向、中心线和定位关系。

布局系统不能删除 requirement，也不能因为文字拥挤而把必需要求降级为参考对象。唯一允许的变化是候选位置、候选侧别、层位、文字方向和引线路径。

### 3.3 尺寸方案和加工表达对象

`dimension_scheme.build_scheme` 产生的是“标什么”的方案，当前对象包括轮廓链、孔链、孔带、总体尺寸、局部直段、半径和孔说明。布局系统读取其结构，不重新计算方案。

新适配器需要下列布局字段；这不是声称它们全部已由 `build_scheme` 直接提供：

- `key`：稳定的尺寸组或说明组 ID；
- `axis`：尺寸链方向；
- `points`、`coordinates`：真实锚点和投影坐标；
- `side`、`allowedSides`：规则允许的侧别；
- `role`：`overall`、孔定位、轮廓细节等语义；
- `columnGroup`：需要共同移动和共线的尺寸组；
- `values`、`combineRuns`：实际尺寸值和 `n@pitch` 组合；
- `reference`：例如 `HOLE_BAND` 参考关系；
- `localAllowed`：是否允许孔旁材料内的局部尺寸线。

| 新字段 | 来源与适配责任 | 缺失处理 |
|---|---|---|
| key、axis、points、side、allowedSides、role、reference、localAllowed | 读取尺寸方案的显式字段；缺省值必须在适配版本中声明 | 不能从坐标接近猜测语义 |
| coordinates、values | 由 point ID 查询 facts，并按已声明测量轴计算；保留原精度 | 缺 point 或轴则 INPUT_BLOCKED |
| columnGroup | 承接上游显式 column；2026-10-31核对当前 build_scheme 未生成列组，旧 native_layout 只透传/布局，不能声称已有更多上游同列语义 | 无列组明确为空；遇显式列组完整校验成员、测量轴与允许侧交集，不从坐标接近猜同列 |
| combineRuns | 语义适配只承接方案显式 combined，经同组孔成员、同列、连续等距及间隔数校验；螺栓孔不组合 n@pitch | 不复制旧布局额外预测的局部组合，不按布局空间改变组合方式；后续增加组合须更新语义契约 |
| requirementBindings | 建立静态对象及动态对象到 requirement 的多对多映射，并交覆盖器证明 | 无覆盖证明不得进入写图 |
| anchorPolicy、representativeFeatureId | 按 §3.3.1 从来源和确认规则产生 | 禁止布局器任意换孔或换锚点类型 |

上述适配逻辑放在新模块，旧函数和旧路线不改。真实基准选择、孔组拆分等若不能由已确认方案提供，建立独立的上游契约前置任务，先完成其设计与验证，不在求解器内补规则。

### 3.3.1 孔说明锚点和静态表达

孔说明保留孔源、成员、数量、孔形、代表孔及 `anchorPolicy`：

- `BOLT_CENTER`：已确认螺栓孔按长向最外侧代表孔的孔心连接，保留 `n*D宽度(总长x宽度)` 和不组合等距的规则。可见 Symbol2 孔/轴符号按上游显示策略承接，不能再重复生成自有孔线；符号实际占用也进入静态障碍。
- `NEAR_BOUNDARY`：非螺栓切割圆孔/槽孔从指定代表孔的真实近侧边界连接。候选记录边界参数；近侧取点随引线出发方向计算，不能把“语义锚点不变”误解为不同文字侧别共用同一个孔壁坐标。
- 半径采用真实弧段锚点；总体直径采用已确认的直径表达。所有连接例外绑定对象及线段角色，不允许豁免穿过无关孔、文字或尺寸线。

以上承接[项目规则](../../skills/tekla-flat-plate-drawing/references/rules.md)中 2026-10-27 的孔源区别。零件号近旁外置和内部特征就近定位采用本方案已记录的后续口径。不得把安装版旧规则中的“所有孔都指孔壁”覆盖到螺栓孔。

### 3.4 主视图几何和静态障碍

旧 `native_layout` 中存在以下能力，作为接口和基线参考，不作为新布局的调用依赖：

- 外轮廓直线和已证明的圆弧；
- 圆孔、槽孔边界和中心线；
- 已证明的坡口/切割终态曲线；
- 视图计划中的剖面或其他静态对象；
- 需要在规划阶段避让的轮廓、孔和模板对象。

新系统把它们统一成只读的 `StaticGeometry`：每条线、弧、圆、孔环和已有表格边界都带稳定 ID、角色、几何和是否允许被尺寸线穿过。现有“尺寸界线可以连接自身锚点”的例外必须显式写入候选关系，不能依赖普通几何碰撞的特判。

首版只承接单主视图所需的终态曲线和固定图框对象；需要剖面表达的零件按 §1 排除，不能把剖面简化成一个障碍矩形后假定已表达。新几何适配器独立转换已证明事实，不调用旧布局流程生成静态几何。

### 3.5 模板快照和纸面条件

正式布局必须使用经核验的现场模板快照，抽象纸张尺寸仅供离线合成测试。输入至少包括：

- 模板身份、属性名称和版本指纹；
- `sheetSizeNative`、图框和可用绘图区；
- 标题栏、表格、固定文字和固定几何；
- 主视图可用区域、固定障碍和边距；首版不添加剖面区域；
- 字高、箭头、尺寸样式和文字方向；
- 视图比例候选 `1、2、2.5、5、10、20、50`；
- 模板中不可覆盖的区域。

模板输入与零件身份、比例和图纸页必须一致。模板清单固定为用户指定的 `零件图10`、`零件图20`、`零件图50`；每项绑定实际图纸属性文件/属性名、模板及表格依赖指纹、方向、尺寸和样式。图纸 Name 只是观察值，不能代替可加载的属性身份，也不能与自有输出图名 `NATIVE-PLATE-R1` 混淆。名称中的数字不推导图幅、字号、视图比例或打印倍率。

20属性内部StyleName没有磁盘文件名的“标准”前缀；50的in_file还含“零件图新50”，与out_file及StyleName不同。两者目前均为 `CANDIDATE_ATTRIBUTE_MATCH_NOT_LOAD_VERIFIED`，不凭字符串相似选择加载文件。10属性采用无 `wdraw_dial.` 前缀字段，20/50采用该前缀；解析必须区分并保留原名，不能把读取不到前缀字段误判为实际图幅不符。10同样只取得候选匹配证据。实际解析路径和所有依赖须在阶段0冻结；文件缺失或指纹变化使对应能力证据失效。

### 3.5.2 采样结论如何进入新系统

- **规格独立**：图框尺寸不是10规格的精确2倍/5倍；按各规格实测值建立快照，不能从名称数字推算。视图比例与图框规格分别枚举，见 §3.8；只使用核验通过的实际方向，不交换宽高制造模板。
- **有效样式**：20/50子尺寸Value的TextElement字高为3，实际尺寸集及显示文字为50/125；50标记通用FontAttr为50/2.5，内容元素和实际显示为125。原始属性、内容元素格式、SDK有效属性和显示图元分别保留并对账，角色样式以核验后的有效结果冻结，不以某个通用字段代替。外层属性与嵌入XML可能采用不同编码，必须保留原字节和分层解析证据。
- **间距与原语**：10/20样例的局部层距为字高4倍，50所采上侧层距约为2.327倍，只作偏好标定证据，不成为全模板常量。样图中的NoArrow/斜划线、孔说明写法、Round框、自由放置等不自动覆盖已确认工程规则；新路线按既有规则配置有效样式后重新标定占用，不能用旧样图占用替代新增/改变原语的能力证明。
- **模板内容与占用**：标题栏、材料表、A–E说明等均纳入固定区域。固定的是位置/公式/布局规则，不代表每个零件显示相同文字；编号、规格、数量、长度、日期、比例及备注按来源形成当前图纸内容快照，再测量实际占用。94图的PL7*520及“1/600起拱”保留来源核验，不能复制到其他零件，也不能因属于表格而遗漏其加工含义；有未进入READY要求的必需加工信息时交上游核验，布局器不自行补语义。
- **单位与视图缩短**：三张图的Scale=1不构成多比例验证。20/50开启了视图缩短选项，50跨度超过所见阈值，但是否实际压缩尚未证明；先按 §4.1.1 核对映射，不能用统一缩放公式掩盖分段压缩。

T02负责模板身份、依赖、内容绑定及单位，T03负责有效样式、占用和原语可控性。已有只读样本作为证据保留，不反复要求用户重选同类图；缺少的属性/字体/依赖先由技术核验补齐，仅剩必须由用户判断的图面偏好再逐项提出。源图采样完成、候选属性字段匹配、完整模板能力通过是三个不同结论，不能互相代替。

### 3.6 Tekla 原生对象身份

写图阶段仍需要当前项目已有的原生身份输入：

- `raw_part.id`、精确 `partPosition`；
- GUID、修改时间和源坐标系；
- 所有权文件登记和自有图纸页；
- 螺栓组原生 ID、目标和位置，用于决定显示/隐藏表达；
- 已有自有图纸的名称、页号和锁定/冻结状态。

这些字段不参与布局评分，但用于写图授权、读回绑定和源模型未改验收。

### 3.7 现有布局上下文中仍可复用的数值

现有上下文仅提供下列参考值，必须经带版本的新适配器转换为不可变纯数据，不能直接复用其闭包或旧布局状态：

- 主视图模型包络 `bounds`；
- 视图比例 `viewScale`；旧 `unit` 含样式因子，不作为新系统单位定义；
- 显示小数位 `decimals`；
- 外包络安全边距 `padding`；
- 模板边界和障碍数据；`fits` 函数不进入 JSON，也不调用旧闭包；
- 静态线 `staticLines`；
- 字体和文字高度配置。

现有 `Arial` 度量和 Tekla 原生短尺寸文字的偏置只能作为带来源的估计输入。不能把估计框冒充保存后的实际字形框。

### 3.8 图幅与比例选择策略

用户已指定使用 Tekla 的零件图10/20/50，不再按物理纸张分类。设计默认 `sheetPreference = [零件图10, 零件图20, 零件图50]`：这是本方案补齐的模板优先顺序，不是用户已确认三者大小或倍率关系。每个模板内按 `1、2、2.5、5、10、20、50` 选择最小合法视图比例分母。模板优先于跨模板的视图比例；图形大小和标注清晰仍须通过 §5.6.1。

求解顺序如下：

1. 按清单核对模板身份、实际方向、单位映射及样式能力。生产模式要求三种规格均已核验；缺失时 INPUT_BLOCKED，不跳过后宣称已选到优先模板。离线研究可显式限定子集，但必须标明未完成全规格验证。
2. 对当前模板按视图比例序列逐级生成候选并求解。每一比例重新计算几何投影与标注占用，不把上一比例的选中坐标整体缩放复用。模板、固定文字与其字号不随视图比例一同缩放。
3. 当前模板全部已验证方向及允许比例均被证明没有满足空间和可读性门的解，才进入下一模板，从比例 1 重新求解。存在多个已验证方向时，长边方向与主视图长边一致者优先，同等时横向优先；每个方向内完成比例序列，不旋转零件主面基准。
4. 每个比例按 §5.5 的局部优先与候选升级顺序处理；允许已声明的零件号/孔说明外置，不改变加工语义。当前模板一旦有合格解，不为改善软评分切换下一模板。
5. 三种模板的全部声明候选均失败，返回具体图框、比例、对象和原因；不临场增大图框、缩字、删尺寸或续页。原生能力缺失与合法候选无解分开记录，前者不能用来证明后者。

图框选择由独立 `SheetPlanner` 负责，核心布局求解器接收确定的模板、样式和比例。模板选择不更改所有权规则，也不授权覆盖同名车间图。

这里“无解”仅指完整生成的声明候选集合被证明不可行。候选截断、求解 UNKNOWN 或预算耗尽返回 SEARCH_LIMIT，停止本件自动比例/模板升级。较后候选可单独用于诊断预览，但不宣称优先性，不自动写图。可读性或原语证据缺失同样阻断自动升级，不能冒充前序模板不适用。最小比例结论只相对于当前模板、方向、候选策略和能力清单成立。

例如零件图10 的 1:5 已完整合格，即使零件图20 的 1:2 也可用，按本默认顺序仍选择零件图10；若前者仅包络放下而图形过小或归属不清，则不算合格。模板更换会同时改变可用区域和样式，不能假设更大名称的规格必然解决问题。

## 4. 新系统的中间表示

新布局系统与 Tekla API、DXF 和现有 `native_layout` 解耦，定义独立的 `LayoutInput.v1`、`LayoutCandidate.v1` 和 `LayoutPlan.v1`。第一版先以普通 Python 数据结构和 JSON 证据实现，不立即引入 C++ 库。

### 4.1 LayoutInput

阶段0已落地的 `LayoutExpressions.v1` 是本节 requirements/语义物件部分的子契约，绑定原生来源、完整要求、上游方案、规则配置、静态/动态责任及逐条覆盖证据。`SEMANTICS_COMPLETE` 只证明责任闭合；无模板内容、单位/可控性标定和实际占用时，不生成可投产 LayoutInput。具体字段见新模块 DESIGN.md。对于已进入事实契约的闭合内切口，适配器保留全部轮廓；上游未给定位尺寸时返回 UPSTREAM_CONTRACT_GAP。这不代表任意真实内切口都已通过几何入口。

2026-10-31当前选择54的实测补充：三个600×300、四角R50的圆角矩形口存在解析候选及双面内环观察，但另外三个切割解析未完成，终态补充路径又报“内口没有唯一制造孔径和孔心”，所以实际停在INPUT_BLOCKED，尚未触发尺寸语义门。按[矩形口诊断与处理设计](../verification/2026-10-31-rectangular-cutout-study.md)依次完成：独立闭合内环来源证明→独立大小/圆角/两向定位方案→布局和原生验收。旧几何、尺寸规则和布局代码不改，完整证据门不放宽；新来源/方案扩展须单独版本化并更新独立核验契约。邻边有台阶时逐口选真实局部基准，本例候选边距285/295/295，不以同形或相同Y坐标推断同一边距。具体数值只是案例证据，不作为规则分支。

同日后续实施已关闭本例几何与尺寸缺口：显式独立来源扩展NativeLayoutSource.v2保留上段旧INPUT_BLOCKED，并通过全部切割、完整实体与材料域对照；轴向矩形/圆角矩形采用dimensionScheme.v2和适配器r2，54的262条语义责任全部绑定，边距285/295/295。真实直段500/200与四角R50共同确定600×300，不机械重复全部跨度。旋转/其他内口仍有独立范围门。新增LayoutPreparation.v1已接入10/20/50采样，明确剩余原语、内容、单位、占用/数值标定与回读门；该报告仍为INPUT_BLOCKED，不是LayoutInput就绪。见[本轮实施验证](../verification/2026-10-31-independent-cutout-implementation.md)。

`LayoutInput` 包含：


templateDigest 绑定模板定义及依赖指纹；contentBindings记录当前零件/图纸字段的来源和公式，renderedContentSnapshot记录实际内容与占用，二者纳入inputDigest。日期等显示字段在本次输入冻结，保存重开后内容变化须重新核验；运行日志时间戳仍不参与稳定摘要。roleStylesNative保存经 §3.5.2 对账的角色样式及证据引用，不能只存一个全局字号。

输入保留带 MODEL_MM / VIEW_MM 标签的原精度事实；候选、模板和求解几何统一为当前模板的 NATIVE_SHEET_UNIT。后文“纸面”均指 Tekla 源图坐标平面，不代表最终打印毫米；样式各角色的字体、字高和箭头以 roleStylesNative 明确记录。缺字段、非有限数、重复 ID、未知单位或版本不兼容均拒绝，不能以空障碍或默认样式补齐。未知必需对象类型报告契约缺口。

### 4.1.1 坐标、视图放置和模板单位

采用右手主视图坐标，归一化源图原点为图纸左下角，X 向右、Y 向上。对世界点 M，以冻结的 `modelToView` 得到以模型毫米计量的 V；已有事实位于该平面时不二次变换。统一坐标形式为 `P = O + c * (V - B) / s`：s 为视图比例分母，B 为主视图几何包络左下角，O 为该基准在源图的放置点，c 为经 API/显示图元对照核验的视图毫米到源图单位换算系数。它不是打印倍率，不能按模板名称推断。原生读写适配另行声明视图局部坐标、视图原点和 FrameOrigin 到统一坐标的映射，防止 API 已缩放的点再次除以 s；往返与多比例标定未通过则阻断。另须核对视图缩短是否实际生效；发生分段压缩的视图不能套用此全局线性映射，未有独立适配及验证则阻断，不能静默忽略压缩。

所有模板边界、字高、箭头、间距和占用均转换到同一源图单位，保留原始值及单位映射证据；尺寸测量值始终由原精度模型锚点计算，不从取整后的布局点反算。有效样式和字段解析按 §3.5.2 执行。各模板可有不同的固定样式；同一模板内切换视图比例不缩字，换模板必须加载该模板完整的已标定样式，不能只增大边框而沿用未核验占用。禁止沿用旧 `unit` 作为单位定义。

[77 图采样](../verification/2026-10-30-77-layout-sampling.md)得到源图 2980×2110、字号 25、视图比例 1，用户确认后续在 CAD 中另行排版/缩放。最新决定以 Tekla 自定义规格验收，因此不需要先取得最终 CAD/PDF 才能开展源图布局开发，也不将源图统一除以 10 变成物理纸张。后续打印质量不在本期 VERIFIED 的证明范围；不能靠人工 CAD 修正来让未通过的源图获得 VERIFIED。

`SheetPlanner` 为当前图框/比例生成有限、带版本的 O 候选：可用区域居中、边界贴合和障碍边界对齐位置，必要时按冻结网格补充。所有 O 属于同一个求解问题，由全局 `placementId` 恰选一个，各对象候选必须依赖同一个 placementId；不得先锁定居中位置后把其他放置可能判为无解。生成范围、步长、上限和裁剪原因进入证据；达到上限但未完成声明集合时为 SEARCH_LIMIT。候选不可行不证明连续平面上绝无解。

### 4.1.2 数值、校准和摘要

- 每个模板冻结以源图单位表示的数值配置 gridStepNative 和 arcChordErrorNative；阶段 0 根据实际量级、最小净距及整数溢出边界选值，阶段 1 用临界间隙测试验证，不继承物理纸张的毫米初值。坐标量化误差上限为半个网格；占用框向外取整、可用区域向内取整，弦误差、量化误差与标定误差共同扩大障碍。配置未冻结不得生产运行；变更须升级版本并重放全部基线。
- 原始模型坐标、原生证据和测量值保持双精度；上游 modelToleranceMm 不作为纸面避让间距，也不作为模型未修改的默认比较容差。显示小数位不参与几何证明。
- 除显式连接例外外，扩大占用后的接触按冲突处理。每种线/箭头/文字/符号角色有明确的最小纸面净距；不能用 Shapely 默认 intersects 代替角色规则。净距、首层最小值、层间最小值来自阶段 0 样式标定；未冻结不得运行生产模式。
- `CalibrationProfile.v1` 绑定 Tekla/字体/样式版本、文字长度范围、方向、比例及原语类型，保留样本量、p50/p99/max 和异常样本。安全裕量至少覆盖已观测最大偏差及数值误差；p99 仅为统计，不能容许其余 1% 碰撞。超出标定域需补验证，不外推为可控。全局标定不可在任务中原地改写；每轮校准产生新版本并重新绑定所有候选。
- 新增 inputDigest 绑定完整输入及模板、规则、能力、标定、预算、pin 的版本；candidateDigest 和 planDigest 绑定对应稳定内容。旧摘要原样保留，不能用新量化摘要代替原生来源重查。
- 新 JSON 固定键排序、稳定对象排序、有限数值序列化与字符编码；原精度事实按固定序列化规则保留，不为摘要把它们降精度。时间戳、耗时和会话日志放运行报告，不进入稳定布局 planDigest。每轮运行报告引用 inputDigest/planDigest，不混用不同版本证据。

### 4.2 LayoutCandidate

每个候选是一个完整可绘制对象或对象组，包含：

- `candidateId`、`objectId`、`kind`、`role`；
- 选定的侧别、层位、基线、文字旋转和纸面位置；
- 尺寸线、界线、箭头、文字框、引线的完整几何；
- 源锚点和源 requirement ID；
- `hardViolations` 预计算结果；
- `softCost` 的分项值；
- 是否依赖其他候选共线、同侧或同组。

另外必需记录 placementId、poolLevel、localityClass、anchorPolicy、静态覆盖关联、占用/校准来源及微调允许域。组候选须列出全部 memberObjectIds 和逐成员几何，禁止组对象与成员重复选择。候选 ID 从稳定内容生成，不依赖搜索发现顺序。

候选必须是真实写图端可以表达的候选。只在离线绘图中好看、但 Tekla 无法控制位置的候选不得进入可行集合。

### 4.3 LayoutPlan

成功结果至少包含：

- inputDigest、planDigest 及全部来源/策略版本；
- 每个 requirement 的静态和动态覆盖证明、实际验证结果；
- 每个布局对象的选中候选和来源锚点；
- 同列、同侧、层位和孔带关系；
- 引线折点和路由来源；
- 硬约束检查结果；
- 软目标分项得分；
- 纸面包络、比例和模板可用区域；
- 求解器状态、搜索预算、版本和确定性种子；
- 未选候选及主要淘汰原因。

失败结果必须包含：

- `status`：`INFEASIBLE_CANDIDATES`、`SEARCH_LIMIT`、`INPUT_BLOCKED` 或 `RENDERABILITY_BLOCKED`；
- 被阻断的 requirement/object；
- 已证明的冲突核心或冲突图摘要；附提取预算和是否完成收缩，不保证全局最小；
- 当前候选集合缺少的能力，例如“无可实现的短尺寸外置候选”；
- 不得只返回 `LAYOUT_OVERFLOW`。

### 4.4 结果状态与证据责任

| 状态 | 含义和后续动作 |
|---|---|
| PLAN_VALID | 离线合法，覆盖、几何及受控外移优先门通过；尚未证明原生图纸合格 |
| INFEASIBLE_CANDIDATES | 声明候选池已完整生成且被证明不可行；不是实际空间绝无解 |
| SEARCH_LIMIT | 候选/模型规模上限，或在无合法解/尚未完成升级优先级证明时耗尽预算；可保留诊断解，不能伪称无解。仅普通软优化未完成按下文处理 |
| INPUT_BLOCKED | 来源/摘要/字段不一致或缺证；包含 UPSTREAM_CONTRACT_GAP 等原因 |
| RENDERABILITY_BLOCKED | 所需候选均缺少原生可控能力，或有限校准后仍无法一致表达 |
| WRITE_FAILED / RECOVERY_REQUIRED | 写入失败或状态不完整；停止本件，按 §5.10 恢复，不能继续自动校准 |
| VERIFIED / VERIFICATION_FAILED / VERIFICATION_PENDING | 图纸验证的独立状态；只有全部必需门通过才为 VERIFIED |

`NO_CANDIDATE`、`STATIC_BLOCKED`、`MUTUAL_CONFLICT` 是 INFEASIBLE_CANDIDATES 下的原因类别，不与顶层状态混用。NO_CANDIDATE 指完整生成后为空；能力不可控用 RENDERABILITY_BLOCKED；未知或失败的生成过程不能伪装为空池。MUTUAL_CONFLICT 包括非碰撞的同列/层序耦合，报告约束 ID。

求解另记 `solverStatus`（OPTIMAL/FEASIBLE/INFEASIBLE/UNKNOWN/MODEL_INVALID）和 `optimizationComplete`。FEASIBLE 可在全部硬门及优先升级证明完成后成为 PLAN_VALID，普通软目标未最优必须明示；UNKNOWN 不等于无解，MODEL_INVALID 是实现缺陷。工程失败归因另列数据问题、特征缺失、评分问题、新类型；无法归入时保留待诊断，不靠更改分类规则消除失败。

覆盖不是“每条要求恰选一个候选”。轮廓、孔形、中心线和标题栏厚度可由静态对象承担；尺寸链可同时覆盖多个位置要求，一条要求也可由多对象联合证明。新覆盖映射连接 requirement→特征→静态/动态对象→观测。模板文字承担厚度等要求时必须读回内容并核对来源；固定文字存在不等于语义已覆盖。参考标记不代表对象可删，是否必需取决于覆盖责任。首版不新增可选装饰对象；必需对象恰选一个候选，固定对象始终存在。

## 5. 求解流程

### 5.1 输入冻结和准入

1. 校验所有 digest、零件身份、坐标系和模板身份。
2. 检查表达要求为 READY，质量问题没有阻断项。
3. 将模型几何变换到纸面坐标，建立静态障碍索引。
4. 将尺寸方案拆成布局对象，但保留同列和孔带的组关系。
5. 为每个对象记录类别，供诊断排序使用；不按类别删除对象或先到先得占位。所有必需对象共同求解。

输入不满足准入时，不进入候选搜索。

### 5.2 区域和基线预分配

先把纸面划分为语义区域，而不是让所有对象在整张纸上自由漂移：

- 主视图内部材料区；
- 孔旁局部区；
- 四侧尺寸带；
- 半径和加工说明区；
- 零件号空白区；
- 模板标题栏和表格禁入区。

区域不是最终位置，只是候选生成的先验。工程禁止区是硬边界；偏好区外但合法的位置保留在声明的扩展池中，不能无记录删除。扩展池和空间放宽分开：增加同一级合法位置不等于允许新语义。局部区域距离阈值以当前模板的源图单位定义并记录与尺寸字高的比值，阶段 0 用认可图标定并冻结，不能按孔径或编号特判。

同一尺寸轴建立若干候选基线。轮廓细节、孔定位、板身宽和总体尺寸分别占有可解释的层级；总体尺寸只能选择对应侧最外层候选。材料内局部候选的可见界线应在允许材料区内，连接自身孔心按显式例外处理；特征近旁的轮廓外侧候选另有 localityClass，不套材料内约束，两者均不得穿无关孔。

### 5.3 候选生成

候选生成按对象类型分开：

**线性尺寸组**：生成侧别、层位、共同基线、短尺寸文字策略和界线方案。整个 `columnGroup` 一次生成，不能把同列成员拆开。

**孔定位链**：保留孔组完整定位、两端边距和 `n@pitch` 组合规则。候选可以在所属边外置，也可以在孔旁材料内置，但不能改变孔组归属或合并规则。

内部特征的定位尺寸按 §5.3.1 优先在特征附近生成局部候选；不能把所有 Y 向定位默认归入整板左、右外侧尺寸带。

**孔说明**：按 §3.3.1 的 BOLT_CENTER / NEAR_BOUNDARY 锚点策略，生成材料内、四侧外置和两段引线候选。候选必须记录连接例外、是否跨孔、跨尺寸线或跨不同孔组；只有当前池级别允许的候选参与求解。

**半径说明**：从真实圆弧取箭头锚点，生成有限方向和距离候选。不能生成完整辅助圆或理论圆弧。

**零件号**：优先生成材料内、无引线、无箭头的文字候选；材料内没有可读空白时，生成零件外近旁的文字候选。文字内容保持精确，不自动增加规格、材质或箭头；标题栏已有零件号作为固定对象处理。

**固定说明和模板对象**：作为不可移动障碍；模板对象若允许有限避让，必须在模板契约中明确，不由求解器猜测。

### 5.3.1 内部几何特征就近标注（用户确认）

2026-10-30 用户确认当前 `[T2-10B-.84]` 图中 Φ150 圆孔的 Y 向定位方式合理，应作为内部特征就近标注的设计依据。现场 API 已读到孔附近的竖向局部尺寸链 `260 + 260`：中间测量点 `(5475.078, 0)` 分别连接上端 `(5255.948, 260)` 和下端 `(5223.692, -260)`，偏置方向 `(-1, 0)`，`Distance=542.359`，当前视图比例为 1。同图另一处局部竖向链显示 `215 + 215`，偏置方向为右。尺寸按特征附近的空间选侧，而非统一拉到整板端部。数值和编号仅作为案例证据，不作为通用规则；完整证据及读取限制见 [现场记录](../verification/2026-10-30-local-hole-y-dimension.md)。

**规则 `LOCAL-FEATURE-DIM-01`：内部几何特征的定位尺寸应优先就近表达。** 其含义是尺寸线、文字及显示界线靠近所属特征，保留正确加工基准和真实测量锚点，不是任意改用最近的点测量。

- 对内部圆孔的 Y 向定位，在孔心左、右附近生成竖向局部尺寸线候选，连接上游已确认的孔心和真实基准边/点；不默认沿 X 方向跨越大段板长到整板左右外侧。X 向定位按对应轴向处理。
- 就近是相对所属特征而言，不等同于强制所有文字都在材料内部：可以采用板内空白区，也可以在特征附近的轮廓外侧放置，但必须让读者明确识别尺寸归属。
- 局部定位与整体尺寸分工：总长、总宽保留外层；孔的两向定位、孔径和数量仍完整覆盖。不能因为局部尺寸看起来足够就删除上游要求，也不重复生成无信息增益的全板闭合链。
- 当已确认的尺寸方案要求上下两侧边距时，在孔旁同一局部尺寸列中表达“下基准—孔心—上基准”，如本例 `260 + 260`；不能将两段拆散到整板两端，也不能仅凭数值相等就删去一侧定位。对边不满足真实基准条件时，不为凑局部闭合链补虚拟交点。
- 局部与远端两类方案都满足全部硬约束时，优先局部方案；只有局部候选经共同让位及合法候选扩展后仍受空间、字高、孔/轮廓障碍或原生可控性限制，才使用较远候选，并记录原因。不能只因远端尺寸更整齐、包络更小或旧生成器仅支持端部标注就选远端。
- 孔心作为尺寸测量锚点，与孔说明的 anchorPolicy 是不同职责；螺栓说明允许指定孔心，普通孔说明采用近侧孔壁。正常连接自身锚点按显式对象关系检查；不得把该规则推广为允许界线穿越无关孔、文字或禁止区域。
- 布局器只移动尺寸位置，不修改基准、锚点、测量值及孔组关系。若当前尺寸方案尚未提供所需的真实基准或局部对象拆分，记录为上游契约缺口，先补表达方案设计，不能在布局器内临场改“标什么”。

候选及计划至少记录来源特征、基准与锚点 ID、局部/远端位置类别、尺寸线和文字到特征的纸面距离、可见界线长度，以及未选择局部候选的原因。不同直径、不同板长和不同位置按同一规则处理，不写 Φ150 或零件号专用分支。

验收：在已核验自定义模板和所选比例下，局部定位清晰可读、无非法冲突；独立检查两向覆盖和真实基准。回归必须包含“长板中部孔应局部标注”的正例和“局部被障碍封死需就近外移”的反例，并覆盖镜像、平移、不同孔径及比例变化。现场样例的偏置数值不得直接用作纸面间距。

### 5.4 硬约束模型

离散求解阶段建立布尔变量 `x[candidate]`。主要约束如下：

1. 每个必需对象恰好选择一个候选。
2. 同一布局对象的候选最多选一个。
3. 几何冲突的候选不能同时选择。
4. 文字框、箭头和不允许穿越的线段不能相交。
5. 引线不能穿过禁止区域，不能与其他引线产生不允许的交叉。
6. 同列成员必须共享基线、侧别和层位关系。
7. 细节链不能排到总体尺寸外层。
8. 总体尺寸必须在对应侧的最外层。
9. 材料内局部孔带必须保持在允许区域内；特征近旁外侧候选按自身区域及锚点策略验证。
10. 零件号优先在材料区内且不穿孔、不穿轮廓；受控外置候选必须位于零件近旁的可读区域，且不与模板、尺寸和说明冲突。
11. 所有选中对象必须落在模板可用区域。
12. 任何被声明为“必需”的对象不能以隐藏、删除或改成参考对象来消除冲突。

冲突候选先通过空间索引预筛，再用 Shapely 精确核验。自身锚点连接、尺寸界线与所属文字的正常连接、中心线穿过所属孔等例外必须以对象关系显式允许。

### 5.4.1 剪枝与分解的正确性条件

同一对象内，只有 A 与 B 的覆盖、侧别/组关系、poolLevel、localityClass、placementId 和 pin 兼容性相同，且 A 的全部外部冲突集合包含 B、A 的词典序代价不优于 B，才能删除 A。所有受影响冲突关系需完整可知；无法证明就不剪。仅按位置接近或代价高不能删候选。不得删除 pin 指定候选。

代价相同时，B 的稳定择优顺序也必须不劣于 A；涉及未展开的多对象约束或非可加全局目标时，不依据成对冲突集推定支配。这样剪枝前后才保持 §5.7 的最终择优口径。

组级 Pareto 配置必须比较外部冲突签名和完整词典序代价；只按组内紧凑度剪枝可能删去唯一全局解。上限造成截断时标 SEARCH_LIMIT，不能以“少量配置”宣称完备。第一版允许保留较多配置，以正确性优先。

连通分量基于完整约束关联图：几何冲突、同对象恰选一、同列/侧别/层序、覆盖、placementId、pin 均连边或超边。全局放置决策可先固定后分解，但必须遍历其声明值并按同一优先级比较结果。只有目标各分项可加、且无跨分量约束时独立求解；否则保留整体问题。包络、空白和全局层数不能未经证明直接按分量相加。

剪枝前后、分解前后与纯 Python 小规模穷举比较可行性、词典序最优值和稳定择优结果。至少包含“组内代价较差的配置是唯一全局解”和“无几何相交但同列约束互冲”反例。

### 5.5 语义硬约束与受控空间放宽

加工语义保持硬约束，纸面位置允许有限放宽。硬约束包括：

- 不改变孔组成员、数量、孔形、尺寸、方向和代表孔；
- 不改变真实尺寸锚点、尺寸值、半径来源和加工表达文字；
- 不把必需尺寸删除、隐藏或改成没有覆盖责任的参考对象；
- 引线必须遵循 §3.3.1 声明的孔心、近侧孔壁、圆弧或直径锚点策略，不能指向虚拟点或无关特征。

允许的空间候选按以下顺序加入：

1. **P0 严格候选池**：零件号和孔组说明在材料内部；引线为直线或已批准的两段折线。
2. **P1 零件号外置池**：包含 P0，并加入零件号近旁外置候选。文字内容不变，不加规格、材质、箭头或引线。
3. **P2 孔组外置池**：包含 P1，并加入按 anchorPolicy 连接的孔组外置候选。路径不得穿过其他孔组、无关文字或禁止穿越的尺寸线。

这些候选是空间放宽，不是语义放宽。计划必须记录使用的候选级别、严格候选不可用的原因、引线长度和折点数量，以及回读后的实际位置。

对固定图框和比例，明确执行以下顺序：

1. 先约束所有内部定位对象使用局部候选；在 P0→P1→P2 中依次搜索，每一级先完成该级声明的合法位置扩展，并共同调整全部对象和视图放置。找到可行解后停止升级。
2. 只有三个池均被证明不存在“全部局部”的共同解，才允许远端定位；此时按远端对象数 k 从 1 到对象总数逐级尝试，每个 k 下再按 P0→P1→P2 求解。首个可行组合确定最少远端数及最低放宽池。
3. 因而局部定位优先于说明/编号保持材料内。外置的“内部无可读空白”指满足更高优先级的全局约束后无共同解，不是单个对象在旧位置附近试放失败。
4. 任一较高优先级尝试未完成证明，返回 SEARCH_LIMIT；不能用超时证明必须外移。对远端对象记录其所属冲突集合，不声称每个对象独立都必须远端；同等最少远端的不同对象组合由 §5.7 评分决定。
5. 固定图框内，比例优先于这些空间偏好：当前比例经合法外置/远端仍有解即保留，不跳到更大比例只为回到材料内。所有比例失败才按 sheetPreference 换下一已核验自定义模板。

实现可以用等价的词典序约束减少重复求解，但必须保持上述可观察顺序和证明责任。池升级不能循环重置预算。

### 5.6 尺寸层、间距和字体可读性

尺寸层不是只要不相交即可。对同一侧、同一轴向的尺寸组建立法向间距约束：

- 第一条尺寸线与几何线保持模板/样式标定的最小安全距离；首层偏好距离由对应模板样例标定，不沿用未核验的物理毫米初值；
- 后续尺寸线优先使用相同层间距，允许在最小安全间距和图幅边界内做有限偏差；
- 相同层间距优先作为组级结构约束，不能让各条尺寸线独立漂移；无法完全相同时必须记录偏差；
- 总体尺寸仍位于同侧最外层，孔定位和轮廓细节不因压缩间距反转层序。

字体可读性是硬门和评分项的组合：

- 纸面文字高度必须落在模板/项目允许范围内，不能因为拥挤无限缩小；
- 视图比例改变时重新计算文字、箭头、层间距和引线的模型坐标占用，不能复用上一比例的布局坐标；模型空间中的等效字高、箭头和间距随比例换算；
- 首版不让求解器选择字号，各文字角色按核验后的样式使用固定源图字高；更换样式属于输入版本变更，不能在失败重试中缩字；
- 任何选中方案都要通过文字宽度、字高、邻近尺寸和实际 DXF/保存重开读回的可读性检查。

多道尺寸线间隔相同和字体可读性优先于单纯压缩总包络；图面紧凑不能以看不清为代价。

### 5.6.1 自定义模板的图面大小与可读性门

用户先提出 A4 优先及标注清晰，后改为直接采用 Tekla 零件图10/20/50，不再区分 A3/A4。前一纸张策略由本次决定替代；“图形大小合理、标注能看清”的要求保留。

- 验收整张 Tekla 源图和关键局部：文字、数字、孔说明、箭头及尺寸归属可辨，轮廓、孔组、缺口、圆弧不混淆；孔符号按实际原生表达核验。整页预览与局部图同时留存，固定预览渲染配置；不得以任意放大后的屏幕观感代替测量证据。
- 同时检查图形相对于可用区的尺寸、关键特征/净距与字高的关系、标注与所属特征的关联。使用源图单位及无量纲比值，不能只要求文字无碰撞，也不能以固定面积占比误拒长窄板。显示缩放和显示器分辨率不进入求解硬门。
- 各模板使用自身已核验的角色字号和样式，不强制三种模板的数字字号相同，不在失败重试时缩字、删尺寸或减小硬净距。当前模板内优先最小合法视图比例分母，避免已有可读大图却继续缩小。
- T03 按各模板建立带版本的可读性配置，冻结关键特征与字高的最小可辨关系、角色净距、图形/标注关系及适用域，记录测量和人工认可依据；由 inputDigest 绑定。77 的层距/字高比仅是观测，不直接成为通用阈值。未标定值不猜测为门槛。
- 明确不满足可读性门时记录具体对象、源图实测值/比值、阈值版本与原因，纳入候选不可行证据；前序模板全部候选被证明不合格后才按 §3.8 升级。缺少证据为 INPUT_BLOCKED 或原生能力阻断，不能当成排不下。
- 离线门通过后仍核对保存重开的真实图面。自动测量未覆盖的整体大小和工程清晰度保留人工项，未确认为 VERIFICATION_PENDING，不得 VERIFIED。需要用户判断时提供按各自完整图框呈现的方案及关键局部、对应测量，不要求预先猜阈值。打印成品验收另行设计，不混入本期源图结论。

回归至少包括：三种规格均合格时按默认顺序选择；前序规格包络能放下但特征不清晰、后序合格时升级；三者均不合格时阻断；前序模板缺标定不跳过；模板字体/固定障碍不同导致后序也失败；长窄板面积占比低但表达清晰时不因此拒绝。

### 5.7 软目标和求解顺序

硬冲突必须为零、必需覆盖必须完整、候选必须可实现；这些是可行性门，不参与软目标。先完成 §3.8 和 §5.5 的模板/方向/比例/远端数/池级别选择，再对该级可行集合按以下顺序优化：

1. 减少允许但不理想的跨轮廓连接；穿无关孔、文字或禁止尺寸线已是硬冲突，不能通过付代价获得许可。
2. 缩短定位尺寸到所属特征的纸面距离、可见界线长度；再缩短引线长度、减少折点。
3. 缩短文字与所属特征的关联距离。
4. 减少同类尺寸层间距偏差、基线偏差，再减少使用层数；首层和层间最小距离仍是硬门。
5. 阶段 3 验证偏好稳定后才启用包络与空白均匀性，默认关闭。
6. 完全同分时，以稳定对象 ID 顺序比较选中候选 ID 元组，不能用候选 ID 求和代替唯一择优。

第一版按词典序逐项求解，已证明最优的前项固定后才优化下一项；每项预算来自全局余额。若软目标未证明最优但有合法解，保留可重复得到的当前解，标 optimizationComplete=false，不声称全局最优。未完成更高优先级证明不得越级优化。等价单目标权重法暂不采用，避免上界估算和整数溢出掩盖优先关系。

### 5.8 连续微调

CP-SAT 选出离散方案后，允许在候选定义的安全区间内做小范围连续调整：

- 同一基线整体平移；
- 文字沿尺寸轴平移；
- 引线折点移动；
- 层间距在最小间距和模板边界之间压缩；
- 零件号在同一空白区域内移动。

微调不得改变 placementId、poolLevel、局部/远端类别、侧别、层序、测量锚点、文字内容和孔组归属。第一版使用确定性的分离约束/最长路径层间距算法；约束图存在环或不能证明独立安全域时跳过该项，不引入坐标下降或 libvpsc。

允许域必须针对已选邻居重新求交，不能沿用单候选对静态障碍的安全区间。孔壁取点及引线折点变化需重新核验 anchorPolicy。每次调整后重算完整几何、覆盖、组关系及词典序分数，仅在全部合法且不恶化更高目标时接受；否则恢复调整前 PLAN_VALID 版本。微调后生成新的最终几何摘要，记录相对离散候选的偏移；验证器不能仍验旧候选框。

### 5.9 引线路由

引线分两类处理：

- 简单孔说明、半径和直径说明使用项目内置的直线或两段折线候选；
- 只有存在多个障碍且候选数量不足时，才使用 libavoid 风格的网格/正交路由生成更多候选。

路由结果必须重新通过工程规则检查。几何上避开障碍不等于工程上可读；跨越无关孔排、穿过禁止尺寸链或从远侧孔壁进入均无效。增加障碍路由候选后，重建受影响的占用和全局约束再求解，不在已选计划上绕线后跳过全局检查。

### 5.10 计划验证和原生回读

布局计划生成后先做离线验证：

- requirement 覆盖；
- 文字、尺寸线、界线、引线和模板边界；
- 同列和层序；
- 孔组数量、孔形和说明归属；
- 计划包络和比例。

验证器读取通用纸面图元和覆盖观测，不读取候选的 hardViolations 作为结论；计划与原生回读分别经独立转换入口生成图元，碰撞判断不调用生成器函数。可以共享 schema 和基础数学库，不能共享已计算的占用结论。验证器先用人工构造的重叠、错锚点、缺尺寸、错厚度和错误连接例外测试，确认能拒绝错误输入。

测量对象和可见文字分别建模：原生子尺寸可能重复报告组合文字，实际显示又可能把一条组合文字拆成多个图元。保留子尺寸→尺寸组→可见文字片段映射，不能按 SDK Value 字符串数量推断重复文字或重叠。77 样例的重复 `6@80` 与显示 `6@`/`80` 片段作为验证器回归证据，不据此改变新方案的螺栓等距表达规则。

写入 Tekla 后执行保存、关闭、重开及 SDK/DXF 回读，绑定 drawingId、源摘要、planDigest 和 attemptId。实际文字、锚点、可见界线、符号、样式、模板和比例是证据；无法取得时为 VERIFICATION_PENDING，不能用计划预期补齐。自动验证未覆盖的视觉项由人工逐项确认，不用截图存在代替 PASS。

| 回读差异 | 处理 |
|---|---|
| 模型、来源、模板、字体或样式已改变 | 当前计划失效，停止本件并重新采集；不进入位置校准 |
| 缺对象、错孔绑定、错值、重复对象或写入异常 | WRITE_FAILED / VERIFICATION_FAILED，保留现场与日志，先修复适配缺陷 |
| 原语占用或 Tekla 自动位置偏差，身份与语义均一致 | 允许记录实测偏差、建立新标定版本或候选禁配，再独立求解和验证 |
| 证据不足，不能区分上述原因 | VERIFICATION_PENDING，停止自动重写 |

每件任务总计最多首次写入加两次校准重写，共三次写入；更换图框、比例、候选池或标定版本均不能重置次数。每次重写前重查来源、所有权、图纸修改状态及锁定/冻结状态；重新生成候选并重走图框/比例/优先级门。三次后仍存在位置差异为 RENDERABILITY_BLOCKED，不无限重试，不用 R2-C 或旧布局兜底。

### 5.10.1 写入状态、失败恢复和源状态复核

新适配器维护单独运行日志，状态为 PREPARED→WRITING→SAVED→VERIFIED；失败转 WRITE_FAILED、VERIFICATION_FAILED 或 RECOVERY_REQUIRED。SAVED 只证明保存成功。日志与现有所有权登记分工：登记负责目标身份与授权，日志负责本次尝试和验收，不能把未验收图登记成合格交付。

阶段 0/4 只在专门授权的测试自有页验证，不覆盖 305/584 已验收页或 101 人工保留页。正式更新前须取得可验证的旧页恢复材料，并记录目标图纸对象清单和指纹。阶段 0 必须实际验证 Tekla 恢复手段；若不能可靠恢复，只能在获准的新测试页形成验证结果，已有页更新和包含该能力的发布门保持未通过，不能自动缩减发布范围绕过。

写入失败或进程中断后保留完整尝试记录，目标页标为待恢复且不可交付，不自动删除图纸或整页重跑。恢复时先读回确认事务走到哪一步，只能操作本次登记的目标和对象；无法确定已完成状态则 RECOVERY_REQUIRED。经验证的恢复流程还须重新核查旧页指纹；不能把“尝试恢复”记为恢复成功。检测到人工编辑立即停止自动恢复和重试。

源状态复核保留精确身份、GUID、修改时间、工作平面和原始几何差异。只读重复采集建立数值噪声基线；阶段 0 单独冻结源状态比较容差和拓扑/属性比较规则，不沿用 0.1 mm 加工几何预算。小漂移只有符合该规则且无任何模型写入、拓扑/属性变化时才可归为读取噪声；来源变化或无法证明时阻断。225 的约 1e-6 mm 差异作为标定案例，不直接写死全项目容差。

## 6. 与现有系统的集成边界

新建独立模块，例如 `independent_layout/`，包含输入适配、纸面几何、候选生成、约束求解、验证、输出适配和回放入口。旧 `layout_solver.py`、`native_layout.py`、`dimension_scheme.py`、几何事实和表达规则不在本次实现改动范围。新模块可以只读调用稳定的事实/表达接口，但不能调用旧布局器作为内部步骤或失败后备。适配层负责：

- 把当前 `requirements`、`geometry`、`raw_part`、`template` 转换为 `LayoutInput`；
- 把 `LayoutPlan` 转换为原生写图协议所需的尺寸、说明、半径和曲线对象，不经过旧 `native_layout.build_layout` 再排版；
- 把 Tekla READBACK 转回统一验证观测。

现有布局实现保留为只读对照基线。阶段 0–5 使用新模块独立入口和输出目录；只有阶段 5 所有发布门通过后，才具备另行规划正式入口切换的条件。正式入口接线不是本次设计修订或独立求解器开发的隐含修改授权；后续任务需明确接线范围及恢复旧入口的方法。

写图安全边界不变：新建图需先取得授权、创建回执并完成所有权登记，更新图必须已登记为 `NATIVE-PLATE-R1` 且身份一致；输出目录必须是新目录。文件输出目录与图纸写入授权是两回事。不改模型、工作平面、车间图和未登记图纸。原有入口仍执行当前仓库“固定图框、比例 50 放不下阻断”规则；本方案的自定义零件图10/20/50 枚举只适用于未来新路线，接线前同步项目规则，不能提前改变旧入口行为。

## 8. 测试和证据计划

测试分四层：

1. **候选单元测试**：文字框、尺寸框、两类孔说明锚点、引线、层位和模板边界。
2. **约束测试**：同列、总体外层、孔带、零件号、引线禁止穿越和共同让位。
3. **求解回放测试**：历史 JSON 快照、固定结果、预算和失败分类。
4. **原生验收测试**：Tekla 保存重开、DXF、视觉图片、源模型不变和图纸所有权。

每个布局规则变化必须追加失败案例、人工期望、证据字段和回归测试。图片通过只能证明图面观察项，不能代替表达覆盖和原生读回。

### 8.1 回归集合与通过率

阶段 0 创建带版本的 caseManifest，按模型身份、实例 ID 和来源摘要去重登记当前 9 件选择、101、225、84 等案例；77、494、94另记为模板采样证据，其几何/表达未审计前不冒充准入成功案例。305/584/六件失败样例与 9 件集合存在重叠，不能重复计数。每件登记准入结论、表达要求、旧证据类型、期望行为、禁止覆盖的现场页和待补证据。84 在独立孔绑定与完整精度补齐前只用于偏好说明，不能冒充已核验几何金标准。

分别报告：准入数/送审数；VERIFIED 数/冻结准入数；有完整归因的失败数/失败总数（无失败时标不适用）。新增准入后契约缺口、图框能力缺口或失败不能移出分母。集合版本变化须列新增/移除理由和新旧集合结果；无解缺陷关闭前发布门不通过。单独的合成异常测试预期为阻断，不混入真实准入成功率分母。

### 8.2 稳定性、性能与 pin

- 同一冻结输入、依赖版本、能力/数值/标定/预算配置，连续运行 10 次，稳定计划摘要和选择结果相同。固定单 worker、种子、对象/约束建立顺序及 deterministic budget；计时日志可不同。跨版本只承诺语义/硬门回归，不承诺坐标和摘要不变。
- wall-clock 只作为运行保护上限，触发即 SEARCH_LIMIT，不返回“确定性的成功”承诺。候选生成、冲突构建、各比例/池求解、核心提取和微调共享一份单件预算，不按重试次数无限累计。
- 初始工程目标：冻结回放集离线端到端 P95 ≤ 60 秒，单件保护上限 120 秒；候选总量上限 20,000、冲突关系上限 500,000。超限必须有阶段、已用量和未完成任务报告，不裁掉对象后继续宣告无解。阶段 0–2 实测 CPU、内存、版本和样本规模，再将版本化配置冻结；需要调整须留下性能证据及不降低正确性的理由，不必让用户选择算法参数。
- 原生往返另计：每次写入/保存/重开/回读初始保护上限 180 秒，总三次；超时不强杀 Tekla，不发起并发重写，先确认事务状态，无法确认则 RECOVERY_REQUIRED。此初值在阶段 0 实测校准，不能将未完成的耗时视为完成。
- pin 是显式输入，绑定来源特征、模板、比例、placementId 和候选 ID。过期 pin 为 INPUT_BLOCKED，合法 pin 之间无共同解则报告约束冲突；不能默默解除 pin。固定某比例的 pin 相当于本次明确限定输入，不宣称跨比例最小。历史图转换到不同自定义模板/视图比例时仅复用语义偏好，不能直接搬旧坐标作为 pin。
- 第一版保证同输入重复稳定，不承诺模型微小变化后整页位置不变。若以后需要“尽量保留上一版位置”，另加有版本的偏离目标，不混入本期验收。

### 8.3 不变量与异常测试

模型整体平移时同步变换来源坐标系、基准和锚点，归一化纸面布局及代价应等价；来源摘要允许变化。纸面整体平移须连同模板、固定障碍和 pin 一起移动。镜像测试仅在样式、侧别、模板障碍、锚点策略和 pin 同步镜像或明确对称时要求代价相同；文字保持可读方向。非对称标题栏或固定侧别下不要求镜像代价相同。

异常矩阵至少覆盖：错模型/摘要、重复或丢失特征、未知单位、非有限数、过期 pin、缺模板/字体、角色接触例外、两种孔锚点、近侧孔壁随路径变化、静态厚度缺覆盖、完整池无解、候选截断、求解超时、组关系耦合、整数化临界间隙、微调恢复、读回对象错绑、三次写入上限、源变化及故障恢复。全局安全门的反例须由验证器独立检出。

三种模板的采样必须转成以下回归证据，不按样图编号写生产分支：

| 反例/触发条件 | 期望结果 | 责任阶段 |
|---|---|---|
| 用名称倍率推算20/50边框，或缺20孔说明样式时套用10的数值 | 检出与快照不符或缺证，禁止进入生产候选 | 0/1 |
| 用Value字高3或通用FontAttr的50/2.5代替实际角色字号 | 与有效属性/实际字形对照失败，不采用错误占用 | 0/1 |
| 嵌入XML误解码、候选文件别名解析错或依赖文件变化 | 明确INPUT_BLOCKED，不能以默认字体/模板继续 | 0/1 |
| 当前零件的表格文字、备注或比例改变 | 更新内容绑定和占用；来源不明阻断，不复制其他零件内容 | 0/4 |
| 已发生视图缩短却仍按Scale线性换算，或自由放置保存后移动 | 独立回读检出不一致；未验证的原语/映射不得视为可控 | 0/4 |

## 9. 风险、暂定决定和待验证项

本节区分用户工程选择与开发必须完成的技术验证。未验证不等于需要用户提供答案，也不能标为已支持。

- Tekla 2017 对短尺寸文字、原生半径文字和缩短界线的实际占用仍需现场标定；在标定完成前，候选框必须保守并标记来源。
- 如果同一 requirement 的所有候选都依赖 Tekla 自动重排，系统应报告 `RENDERABILITY_BLOCKED`，不能把不可控位置当成可行解。
- OR-Tools 的整数化精度、求解超时和打包方式需要在项目 Python 环境验证；第一版可保留纯 Python 的小规模穷举作为诊断工具，但不作为生产后备。
- Dymo 模拟退火暂不进入生产链。只有在硬约束和确定性评分稳定后，才评估把它作为二次质量优化器。
- libavoid/Adaptagrams 暂不作为强制依赖。先用候选折线解决当前样例，若引线候选数量成为主要瓶颈，再做 LGPL 依赖评估。
- R2-C 仅保留为可选诊断和温启动研究，不是首版必需交付或阶段前置，不作为生产兜底。若以后接入，必须仍通过语义硬约束、字体可读性、指定自定义模板和 Tekla 可控性门。
- 平直板准入范围内的最终 100% 是验收目标；任一 READY 平直板在三种指定自定义模板和视图比例序列中仍无最终通过结果，都生成缺陷记录，不通过缩小准入范围、换用清单外图框或临场改规则消除。
- 图幅必须从已验证且获准的零件图10/20/50 候选中选择；字号不缩、必需尺寸不删、模型不改是本项目不变量。新求解器不能通过使用未验证图幅或放宽这些不变量取得表面成功。
