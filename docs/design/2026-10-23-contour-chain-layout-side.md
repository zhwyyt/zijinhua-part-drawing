# 轮廓尺寸链按锚点就近选边

## 失败与范围

用户复核 M4 自有试验图指出：上方凹口的 `109｜58｜400` 链放在下方；锚点、表达意图和文字样式均正确。原 `contour_chains` 按绕向和单调段方向给出外法向侧，凹轮廓的外法向并不代表尺寸链靠近哪一侧。这是布局评分问题，不是模型数据或尺寸选择问题。M4 的保存读回 PASS 未覆盖该审美缺陷。

## 设计

沿用 P2/P5 分层。P1 及 P2 的链生成、补齐端点、合并、闭环坐标分配顺序全部不变。P2 在完成选择后声明 `allowedSides`：普通轮廓链允许正负两侧；总尺寸、同列组及其他组保持原侧。已有 `side` 仍是首选侧，用于距离近似相等时稳定决策。

P5 对允许的每侧计算全部已选锚点到该侧包络边的垂直距离总和；选总距离最小者。两侧总距离差在 `锚点数 × modelToleranceMm` 内时保留首选侧。包括闭合端点在内的每个真实锚点均参与，不按零件号、凹口编号或局部固定坐标特判。评分使用模型单位，与字号/比例无关；层距、总体外置及后续碰撞门沿用现有机制。每组记录候选距离、首选侧与最终侧，便于追溯。

不增删或合并尺寸、不改锚点、数值、组合、层级或文字样式。只允许侧别及受其影响的层距/界线/视图居中变化。该修复不是 M5 有界回溯的全部实现，也不承诺距离最短就是任意图面的全局最优布局。

## 2026-10-27 斜边按所属边锁定

包络距离会把下边锚点放到上方：斜板左端高，下边站点到全局上边的距离仍更短。界线从包络上边引出后，会落在没有拐点的上边线上。

轮廓链在两侧都有可比站点、且每个站点都在另一条链的同一侧时，锁定到该侧：横轴上方为上边，下方为下边。总尺寸、同列和孔链仍按原规则。投票分裂或没有对照链时，仍用包络距离。锁定后求解器不再把这条链换到对边。

轮廓链的界线从锚点向外空开，不再改从包络边起笔。射线若进入板内，该站仍用包络外侧，避免界线穿板。锚点、尺寸值不因此增减。

## 保存读回发现的文字背景范围

首轮现场已完成换侧，但外层界线在内层“58”文字处被 Tekla 正常裁断。旧读回使用字形墨迹框加 0.2 字高解释背景，忽略字体侧边留白：实际界线 x=158.506，字形右界152.645、排版右界153.949，字高25；前者加5仍够不到界线，后者可以。DXF 原生文字排版框由 `ezdxf.bbox` 按文字插入点、字体、宽度因子和旋转计算，独立于计划。

渲染读取同时保留字形框（穿字碰撞检查）和排版框（背景裁断见证）。后者仍只加原有0.2实测字高，并要求剩余可见界线全部由实际DXF线段覆盖；不扩大固定容差、不凭SDK存在接受缺线。保存失败记录及正反回归，缺文字、缺线或超出排版框的缺口仍失败。

## 验证

1. 实测凹板复现：七组内容与 M4 保存证据逐字段一致；`109｜58｜400` 在上，`50｜506｜11` 在下；PLAN/覆盖/可读性通过。
2. 独立凹轮廓的镜像、旋转、平移、缩放：就近侧随几何变换；总尺寸/同列/单侧约束保持；近似等距保留首选。
3. 七件历史基线与车间案例回放，检查内容不变及侧别差异；完整回归。
4. 同一自有图 API 写入、保存重开、独立 SDK/DXF 与图面验证；仅在没有活动图时执行，不接管原车间图。
