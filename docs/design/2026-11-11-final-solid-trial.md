# 最终实体路线：独立离线试验方案

日期：2026-11-11。状态：试验设计，尚未实现或运行新路线。

本方案属于[阶段主规划](2026-11-04-facts-and-two-layer-quality.md)的阶段0，不另起布局路线。用户希望先验证“最终实体＋已确认的必要补充规则”，效果好再采用，效果不好继续使用原路线，原代码不受破坏。本轮完成隔离、比较与采用条件设计；代码实施及实际结果另行记录。

## 1. 试验要回答的问题

同一份Tekla读取快照，能否不重演切割过程，直接从最终实体取得完整、正确的几何事实，并生成没有遗漏的加工表达？结果必须能指出每个面、边界、孔、切口和坡口的归属及依据。

新路线不得通过调用旧几何审计、旧分类路由或旧切割推导来取得最终答案。旧路线独立运行，只作对照。新路线无法解释的地方如实报告，不能自动回退旧路线后合并成“新路线成功”。

## 2. 如何保持原代码不变

试验前记录Git提交、工作区差异、现有生产源码及测试文件摘要、输入快照摘要和依赖版本。本次检查基线为`91925d3beecf29c22b315c8ccf395374eb276cca`，开始设计前工作区干净；正式实施时重新记录，不能使用过期基线。

计划新增独立包`src/zijinhua_tekla/part_drawing/final_solid_trial/`和对应独立测试文件。入口采用该包自己的`python -m`离线命令（待实现），不改现有CLI注册、`draw-native-parts`或旧几何/表达函数。旧代码不导入新包，新入口不触发Tekla连接或任何写图操作；独立模块有正式测试与文档，不把一次性脚本当生产实现。

可以只读复用已核实的基础数学、线弧处理和纯表达构造函数；逐项列出依赖，禁止借复用绕回旧切割核验链。不为方便试验重构共享函数，不改已有测试的期望来制造通过。确需修改共享接口时，作为后续独立变更评审。

所有试验输出写到新的本地`outputs/final-solid-trial/<run-id>/`，不覆盖原始快照或历史报告。输出目录已存在就拒绝运行。保留输入摘要、两路完整报告、差异表、解析卡和简图。

独立包和单向依赖是基本隔离，Git分支可额外用于保存试验版本，但分支本身不是行为隔离。本轮不需要复制整套旧系统。实施前后用源码摘要、差异审查及旧回归证明原实现保持；不安装或升级正式环境依赖。

## 3. 新路线的数据边界

主线：最终实体 → 完整性检查 → 面/边及局部区域关系 → 特征解释 → 加工表达。类型由事实解释，不把旧平板分类作为读取最终面的前置条件。

| 输入 | 新路线中的作用 |
| --- | --- |
| 最终实体的面、环、边和解析参数 | 决定最终几何；数值异常、读取不全、拓扑矛盾及精度不足明确报告 |
| 坐标、对象身份和来源状态 | 确保比较同一对象与版本，建立局部坐标，不能悄悄修正或吸附真实几何 |
| 螺栓组/孔证据 | 沿用已确认的孔规则，校验目标归属、位置、轴向和实际局部厚度区域；焊钉不当作孔 |
| 切割圆弧的补充证据 | 只用于既有规则允许的圆弧来源、参数与拟合误差确认；不重演全部切割，不将普通折线自动圆滑化 |
| 原始实体、建模轮廓、操作历史 | 默认只保留在旁路对照资料；圆弧补充规则确需的部分可显式读取并记录用途，不作为普通面读取的准入门 |
| profile等声明属性 | 保留规格及冲突诊断；不覆盖实体测量。若同一实体确有多种有效解释，报告歧义或明确所需补充依据，不能声称仅靠实体已唯一确定 |

沿用规则不等于扩大规则：孔补充和圆弧补充均保留适用条件、证据来源及失败状态。普通切割历史缺失或无法推导，不阻断实体已能证明的事实；必要的孔/圆弧补充证据缺失则影响对应特征，不能用“最终实体优先”忽略它。

每个面必须有角色或未解释原因；共面合并后保留原面映射，不吞掉小坡口、微小真实台阶和内部边界。完整性不能仅用“所有面都被贴了标签”证明，还需相邻关系、闭合边界、面几何一致性及特征范围核验。不能用“最小面距就是板厚”作为所有零件通用规则。

平板输出轮廓、厚度、孔槽、切口、圆弧及适用坡口事实；折板补板段、连接、折角/折向、孔所属段等关系；型材后续补腹板/翼缘与截面、端切关系。中面几何展开与制造下料展开分别报告，缺少展开口径不能宣告下料尺寸合格。

## 4. 先用什么样本试

先离线回放已有证据，不需要为试验修改模型或重出图。运行前冻结样本清单、特征覆盖、输入摘要及预期，保留失败件；固定分母，不看结果再删样本。

第一批分两组：

- 平板基线：从现有真实夹具及测试中选普通轮廓、螺栓圆孔/槽孔、布尔切口、切割圆弧、坡口/剖面以及操作推导曾失败的样本。现有`tests/fixtures/part_drawing/`、`tests/fixtures/native_sections/`和相关测试可提供输入；确切数量在清单冻结时报告，不在设计里虚称已全部可回放。
- 折板扩展：现有`outputs/part-facts/20261105-probe-01/evidence.json`含首批6件的读取资料。其解析卡和简图是独立核定参考，不直接视为真值；现有样本仅覆盖尖角`PolyBeam`折板，不能据此宣称已支持`BentPlate`、带半径折板或型材。

直型材及带半径折板在本轮方法成立后再补代表样本与专属契约，不在首批试验中一次铺开所有类型。平板用于证明不退化，折板用于证明新方法能扩展。

## 5. 怎样判断试验结果好不好

按事实和表达含义比较，不按JSON逐字相等：两路可能使用不同坐标原点、点序和特征ID。先在明确的坐标变换下对齐，保留侧别、手性和原始精度，容差来自读取精度和已有依据，不为了匹配临时放宽。

| 比较项 | 必须回答的问题 |
| --- | --- |
| 几何完整 | 每个面/边界是否有解释？是否遗漏孔、切口、坡口或弧段？ |
| 数值及归属 | 厚度、长度、角度、孔径及位置是否正确？孔属于哪个板段/腹板/翼缘？ |
| 加工表达 | 应交代的形状、尺寸、定位、方向及剖面是否齐全？是否丢失原本应有的责任？ |
| 新旧差异 | 相同、旧错新对、新错旧对、都未解决分别多少？证据是什么？ |
| 可信边界 | 已证实、矛盾、缺证、不适用和未支持是否区分？有无错误放行？ |
| 原实现保护 | 原文件摘要是否不变、原测试是否通过、独立运行旧路线结果是否保持？ |

旧路线不是绝对标准。两路不一致时，依据源实体、独立测量及人工核定判断，不能为了对齐旧输出把新路线改错；两路一致也不能替代独立证据。

必须补以下反例与变体：移除一个必要面、错误法向或边界连接、重复/退化面、缺失或冲突孔证据、曲线参数不足；平移旋转、面/边枚举乱序、合并与拆分共面面；保持最终实体和必要补充证据相同，改变无关建模历史，几何事实与表达应保持一致。镜像应正确改变侧别，不要求结果无差别。

已知应阻断的旧用例要区分原因：实体损坏/必需证据不足仍须阻断；仅因无关切割历史无法解释而阻断的，允许新路线成功，但必须有完整实体证据。不能以复制旧拒绝结论验证新路线。

成功条件：冻结首批支持域的独立核定正例全部正确，几何和表达没有退化，必需反例没有错误放行；历史依赖变体符合预期；报告所有差异及未支持域；原源码与正式入口保持，相关及全量回归通过并确认导入当前`src`。不能用“通过率更高”或“简图看起来正确”单独判定成功。

## 6. 如何采用或停止

试验失败：正式入口一直使用原路线，停止调用新入口即可。保留失败证据和试验代码供分析，不执行全仓库回滚，不删除用户改动；不需要靠恢复备份修复原系统。

试验成功：先报告明确通过的类型和特征范围，再提交一个小的接入变更，让已验证范围使用新事实提供者，保持加工表达接口和后续方案/布局边界。扩大支持范围逐批验收，不凭6件成功替换所有类型。正式切换前还要验证适配后表达等价及下游回归，必要的现场核验另行安排。

旧提供者至少保留一个验收周期，接入切换集中在一个位置，可显式选择恢复旧提供者。新路线运行时失败应报告失败，不隐式调用旧路线冒充成功。若日后允许按能力范围使用旧路线，必须在报告中标出实际路线，并记录覆盖范围，不能隐藏。

## 7. 实施步骤与本轮边界

1. 冻结基线、输入与独立预期；记录两路需要的证据，核定首批支持域。
2. 在独立包实现最终实体事实、必要补充规则及表达适配，运行离线对比、反例和回归，提交逐件解析卡、简图和差异报告。
3. 根据验收结果决定采用范围或停止；采用时单独做最小接入变更并验证，不在试验过程中顺手接入。
