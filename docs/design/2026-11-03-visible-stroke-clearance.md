# 可见笔画与净距基础适配

范围：离线重放已登记的17/18/19试验页；不写Tekla、不改正式入口、不发布CalibrationProfile。沿用真实字形/原语报告的摘要与独立图框映射。

## 已知问题与口径

上一轮15个案例是原生中心线与遮罩/墨迹并集相交；不能据此判可见穿字。PDF实际使用白色填充、非零笔宽、butt端帽、miter连接、空虚线数组和页内多边形裁剪。pdfminer的W/W*是空实现，因此不能把其path直接当最终可见占用。

1. 新增独立只读适配，按PDF操作顺序保存q/Q图形状态、CTM、裁剪及黑白颜色；只支持不透明黑白、简单直边裁剪/白遮罩。未知绘制、透明、混合、软遮罩等拒绝，不猜。
2. 使用现有PDF路径和独立图框映射，将待测直线先在PDF用户空间按实际线宽构造butt笔画，再变换到源图坐标，支持非均匀变换；裁剪后按顺序扣除后绘制白遮罩。零宽hairline、待测虚线/非butt端帽等明确阻断。黑色箭头按实际填充三角形参与同一可见处理。
3. 原生线按几何唯一关联实际PDF线组；完全重复的原生线须有同等数量、相同几何的PDF绘制，保留整组nativeIndices和各pdfPath，不伪造一对一顺序。近似但不同、数量不符、缺失或跨组复用均阻断。报告未遮蔽笔画、可见笔画面积及距离，明确到每字墨迹包络与保守占用框的两种度量。包络碰撞只表示候选冲突，不能冒充精确字形轮廓相交；不设未经验证的角色净距阈值。

## 验证计划

- 合成真实PDF回归：遮罩在前/在后、q/Q裁剪恢复、线宽造成中心线漏检、非均匀变换、hairline、虚线、透明/未知状态拒绝、证据摘要不匹配。
- 重放10/20/50各12个原语，输出逐线/箭头证据与汇总；检查现有渲染及局部放大。
- 相关测试及全量unittest，确认src导入与原125文件哈希；更新STATUS/TASKLIST和验证记录。

尚未覆盖：字形真实填充区域布尔运算、字形本身被后续绘制遮挡、任意曲线笔画、彩色/透明绘制、设备hairline、物理打印与真实视图单位往返。输出始终productionEligible=false。

## 实施中核实的边界

- pdfminer 20251230在`w`时按CTM第一列长度缩放lineWidth；旧报告此字段不是原始PDF用户宽度。新适配直接从PDF指令读取宽度，在实际绘制CTM下构造几何，旧证据不重签。
- 页面有非isolated、非knockout的DeviceRGB Transparency组；仅接受这一明确组合，且所有alpha必须为1，任何其他ExtGState效果拒绝。未把组名称本身当作半透明绘制。
- 只支持简单单闭环裁剪/白填充，实测裁剪为矩形；裁剪在当前路径绘制后生效，q/Q恢复，白遮罩本身先裁剪。填充箭头可带miter轮廓，但到达miter截断回退的情况拒绝。
- 不把非目标黑色曲线路径展开为笔画；黑色不会擦除目标黑色笔画，目标测量仍仅含本样例线和箭头。结果不是全页障碍检查。白色曲线/文字/描边不能静默忽略。
