# 全页障碍核验与有限引线候选

## 本轮边界

承接已证明的真实视图坐标链，实现独立布局模块里的全页障碍索引、原语冲突报告和有限引线候选，不再把一次性analyze.py当实现。只用已有六页原生证据离线回放；不写Tekla、不改旧入口，不在缺完整角色样式时宣称生产布局完成。沿用已接受的轻微短尺寸箭头削边，例外必须绑定实际证据中的具体箭头，不采用通用8%百分比门。

## 契约和责任

`PageObstacleStudy.v1`绑定同一capture、PrimitiveStudy、GlyphOccupancyStudy、PDF摘要及源图尺寸。重新解析PDF绘制顺序，核对原语路径归属。全页文字逐字墨迹包络、白色遮罩、黑色笔画/箭头进入STRtree；未支持的有限曲线路径用控制点包围框加CTM/笔宽/miter保守范围，未知设备hairline等不可界定对象保持未解决。缺字/不支持字体不能因位于表格就丢弃，保留全页缺口，报告永不等于生产通过。

原语核验分别报告：文字对其他字形/可见路径、原语可见路径对其他文字、箭头遮挡和完全隐藏线、页面越界。自身尺寸正常遮罩断线保留为观测，不把所有遮罩裁剪都判作缺失；完全隐藏的线单列。箭头例外通过调用方列明的已接受证据键（primitiveDigest/key/pdfPath）精确匹配，实际丢失面积必须与证据相同；未知例外或篡改拒绝。无例外的损失不能静默放行，极小浮点尾差只按数值精度排除。

候选首版只做已有原生引线文字的刚性平移与有限直/折线路径，不估算新字符串或新字体。固定原锚点、字号、实际字形/遮罩和已测箭头方向；从实测首段方向建立箭头后方短段，从文字实际左侧端点接入。枚举显式给定的源图偏移和折线通道；所有数量有限、确定性排序，池内无解不代表全域无解。

候选检查与生成分离。检查器使用全页原始黑色几何（包括被旧文字遮住的线）、白遮罩和字形，避免移动旧遮罩后漏出隐藏障碍。只移除被移动对象已唯一绑定的路径、字形和文字遮罩；共用路径或遮罩归属歧义拒绝。相交几何记录障碍ID，不整体跳过一个对象。自身锚点连接只豁免真实首段/箭头与已绑定目标轮廓在数值接触邻域内的交集，不豁免文字、遮罩或无关线。所有候选保留原锚点与实际样式证据，标记需要原生回读；缺字等全页缺口仍阻断生产。

候选不联合移动既有模板编号/尺寸，也不逐个贪心选定后冒充共同解。输出每条引线的有限候选及冲突原因、可用候选间的成对冲突，供后续联合求解使用；本轮不实现CP-SAT、尺寸组移动或完整加工覆盖。原锚点被固定编号遮住时应明确无可用候选，不能移动锚点绕过。

## 实施中的连接边界

锚点处首段天然没有正净距：只对已匹配的目标轮廓线允许首段/箭头连接，实际有宽笔画交叠必须位于按笔宽和0.1关联预算计算的局部邻域，后续折线仍保持正净距。不得把所有接近锚点的线或文字一并排除。文字端的实际保存端点与自身遮罩之间存在固定小间隔，允许该最后一段保留原生连接间隔；仍禁止穿自身遮罩/真实墨迹，其他段保持净距。两个连接例外均有反例回归。

同批声明可动的引线在静态索引中统一移除已绑定旧图元，使用未被旧遮罩裁掉的原始几何作为其余障碍，再输出新候选之间的成对冲突。未支持的完整字体问题列入unresolved，KNOWN_GEOMETRY_CLEAR仅说明已知几何，不转成生产可行。首版保守禁止与固定黑线交叉，尚未按不同尺寸线/界线角色细分例外，因此固定尺寸框围住原锚点时可能整池无解；不能借此声称需要换图幅或零件无法布局。

## 验证计划

1. 合成PDF回归 → 绘制顺序、可见/原始障碍区分、笔宽、未知曲线/缺字、摘要/归属错误、精确接受例外及完全隐藏路径。
2. 候选几何回归 → 固定锚点、文字平移、静态障碍、局部端点例外、隐藏线恢复、无解/有限池状态、成对冲突、确定性与平移等变。
3. 六页离线回放 → 重现20/50严重遮箭头及引线碰字，保留8%已接受样例；候选报告可审查且不误称原生成功。相关/全量测试、旧文件哈希和文档同步完成后交付。
