# M4 实时模板快照与 P4 接入

依据：[规划架构](2026-10-21-native-planning-architecture.md)、现场只读探测。范围是 M4，不实施 M5 回溯布局。用户本轮另授权修复已复现的 P2 重复坐标问题，见专项设计；模板布局本身仍不改变尺寸方案。

## 已知事实和边界

- 普通 Drawing 对象没有返回当前图的模板表格；公开 PresentationModel 通道已实际返回表格边线、文字、内外框和说明。
- 表格行数由目标零件决定，不能把另一张图的表格快照作为目标图的最终占用区。
- 口径 v1 固定比例 1:1，图幅由实际目标模板取得，字高 25；布局间距随样式单位转换，几何锚点和值不变。
- Presentation TextPrimitive 没有精确字形框。本阶段采用显式保守预留，不能声称精确字体量测。
- Tekla 2017 插入图纸要求没有活动图纸。不得自动保存或关闭用户当前打开的车间图；写入口在改变工作平面前检查并拒绝该状态。用户自行保存关闭后才可执行现场写图。

## 流程

1. 读取目标模型/零件原始证据，重跑现有几何与表达门。未 READY 的零件不创建图纸。
2. SDK prepare：在无活动图纸时，只创建或访问自有 `NATIVE-PLATE-R1` 图。可显式传入图纸属性文件；省略时采用 SDK 默认属性，快照标记未确认。已有图严格沿用所有权登记，不加载新属性覆盖它。
3. 新图的自动生成标注登记为本次自有准备对象，以便后续写入替换；已有图仍拒绝人工标注。准备后保存自有图，读取其图幅、比例、模型身份及纸面 presentation，关闭自有图。提前记录准备图页号，规划失败仍保留可追溯的自有图。
4. Python 把实时原始采集归一化为 `nativeTemplateSnapshot.v1`，与来源及哈希同批保存。P4 仅消费快照，不连接 Tekla。
5. P4 在固定图幅和 1:1 下选择能容纳视图包络的空白矩形，输出 `viewPlan.availableArea`、模板指纹和样式。放不下明确失败，不回退固定预留或缩小比例。
6. 写图前 SDK 再采当前目标图模板并核对指纹，然后替换自有标注。视图按 P4 的可用矩形放置，实际 Width/Height 放不下即失败；删除 C# 固定 45 mm 预留。
7. 保存关闭重开，再读取模板和实际视图框，核对指纹、图幅、比例、可用区、表格避让。沿用表达覆盖、DXF 和来源复查。

## 快照与区域规则

- 来源：模型路径、采集时间、目标零件 ID、页号、图纸 Mark、属性文件请求值/未确认标志、SDK 原始采集指纹。
- 坐标：纸面毫米。用实际 Drawing.View 原点排除 presentation 中的模型视图；只允许唯一的纸面层，不以某个 Segment ID 或零件号裁决。
- 图框：在纸面层的实际轴向线段中识别四边闭合、宽高均不少于纸张 80% 的框；最内层框作为页面内部范围。只排除构成这些框的边线，不丢弃同 Segment 的表格/说明。没有可信框则阻断，不能把整张纸默认为净空。
- 表格/图形：剩余实际线段和已支持图元形成占用证据；不依赖 ObjectType 数字或模板名称。未知图元阻断，不静默忽略。
- 文字：支持水平/垂直文字及偏差不超过 0.001 弧度的小角度；水平文字在整个内部宽度上预留基点上下各两倍字高，垂直文字在整个内部高度上预留基点左右各两倍字高，并按纸张跨度增加小角度漂移，再加安全间距。实际公司名称存在微小角度，水印为垂直文字，均不能静默忽略。此策略不猜字宽，可能过度预留；其他倾斜文字进入不支持，留后续字体框采集。快照明确记为保守文字带，不能称作精确字形框。
- 安全间距为字高的一半，记录在快照；当前样式字高 25，即 12.5 图纸单位。表格及文本预留不得与实际视图框相交。
- 用障碍区域边界构造确定性的空白矩形候选，选择能容纳本件视图包络的最大矩形，平局按坐标稳定排序。该步骤只是 P4 视图区域选择，不重排或删减尺寸方案。

## 接口与兼容性

- `build_layout(..., template=...)` 新增显式快照输入。旧离线基线调用未给快照时保留原行为，仅用于历史回放；正式 `draw-native-parts` 必须经过 prepare 和实时快照，不接受无快照写入。
- CLI 增加 `--drawing-attributes`，只用于新建自有目标图；本机候选 `标准零件图10(按1倍导出)` 已找到，但文件名存在不等于车间确认。
- 桥接器增加 prepare 模式；已有 write/audit 同样不得自动保存用户图。最终版本不读取总图纸目录，定向身份查找方式见后文现场兼容修正。
- 所有权登记记录准备成功的页号；后续失败不删除图纸、不伪装完成。不自动无限重试。

## 验收计划

1. 现场采集 fixture：能分离内外框与同组标题栏，材料表和说明不得消失；完整复现指纹与坐标。
2. 变体：改变页幅/表格行数/平移/文字位置，区域结果随证据变化；未知图元、倾斜文本、缺框、非有限数、模型/目标不一致均阻断。
3. P4：可用矩形与所有障碍无交集；超大视图失败；历史 P2 方案与锚点保持一致；正式流水线不能跳过模板采集。
4. 写图：缺少快照、模板变化、非自有活动图、所有权不明都在写前拒绝；实际视图框复读再核对，不能只核对计划。
5. 编译 SDK、相关单元测试、完整 `python -m unittest discover -s tests`；确认 import 来自当前 src。
6. 当前车间图关闭后，用当前已明确实例 `319054722 / T2-11P-132` 创建一张自有图，保存重开、SDK/DXF/模板与源字段复查。验收通过才标 M4 完成。

## 现场兼容修正：禁止全目录查找

首次运行发现 Tekla 2017 的 DrawingEnumerator.AutoFetch 抛索引异常；普通目录读取仍过慢，已在创建目标之前停止。正式流程移除 GetDrawings。新登记从第 1 页调用 Insert（只创建，碰撞即失败，不调用 Modify 覆盖）；登记中已有目标时，只按该图的数据库身份 Select 读取。旧登记缺少数据库身份时阻断，不能猜测或退回总目录。

2017 未暴露公开按数据库 ID 取 Drawing 的入口，单凭 PartIdentifier/SheetNumber 构造再 Select 已实测失败。兼容层仅读取/设置 SDK 内存句柄的内部 Identifier/DrawingIdentifier，然后调用公开 Select；不调用内部数据库写函数。每次 Select 后仍必须核对模型、名称、目标实例、登记页号及冻结/下发/锁定状态，再允许打开和修改。内部身份访问隔离在单一兼容文件，缺字段或查找失败均阻断。正式跨进程读回需现场验证。

新图在 Insert 成功后立即写出身份收据；准备失败也保留收据，Python 登记为 INCOMPLETE，不自动接管其未标记标注。未知旧图保留，不以缺失登记为由删除或接管。新建页号冲突保留失败证据，不扫描或自动递增重试。


## 目标模板及 25 字高现场适配

本机候选属性同时自动创建 FrontView/TopView。新图 Insert 后仅保留唯一 FrontView，移除本次自动创建的其他视图；已有图若不止一个视图仍拒绝，不删用户追加视图。未完成的本次新图以确切创建收据单独恢复，不把任意 INCOMPLETE 图自动当成可接管对象。

M4 的 display.shortDimension 明确为 Outside，交由 Tekla 原生短尺寸布局处理；保存读回核对该属性。锚点/值/尺寸组不变，不实现 M5 搜索或删除短尺寸。DXF 标签查找距离由实际保存的字高换算（尺寸/普通注释为 4 倍，R 为 16 倍），替代旧的固定 2.5 字高距离；仍要求实际 DXF 标签与 SDK 数值对应、文字不得被穿线。若原生外置仍发生冲突，保留失败而不是放宽质量门。

现场 DXF 会在文字背景处裁断自有界线。独立读回只允许实际导出文字框及 0.2 倍实际字高的边距解释遮挡；其余可见界线必须完整有 DXF 证据，完全缺线和遮挡外缺口仍失败。该行为已由现场 109 文字遮挡及正反回归验证，SDK 界线端点/样式核对不变。
