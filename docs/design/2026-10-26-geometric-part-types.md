# 通用几何事实之后判定板件类型

日期：2026-10-26。用户确认类型指平直板、折弯板等几何形态，不指连接板/加劲板等用途。

## 分层与范围

原始读取 → 通用几何事实 → 几何类型判定 → 对应专用核验 → 加工表达 → 布局/写图。

- 原始运行时类型只用于理解API字段（ContourPlate轮廓是板边，PolyBeam轮廓是路径），不作为几何类型标签。
- 通用事实记录RAW实体的平面、轮廓、完整挤出方向/截面和跨度；复用已有全壳/边核对，独立于孔、坡口及出图方案。不以PL规格、构件编号或分类名称生成几何。
- 分类结果独立记录 `type`、`status`、`basis`、`sourceRefs`、`route` 和未解决项。分类不是加工终态证明；平直原板带坡口/槽孔仍走平直板专用核验，只有其最终材料和来源也通过才可规划。
- 平直板：完整平行双面挤出、唯一薄向。已有ContourPlate的解析轮廓提供曲边原板的几何候选，RAW缺失的旧证据也可按实际平面轮廓进入旧专用证明；不能因旧证据没有RAW而静默把最终实体当原板。
- 折弯形板：有限直边恒定截面的等厚折线带，以截面中线的等厚偏移重建并核对完整截面。只确认几何形态，不证明实际冷弯/热弯制造来源或折弯半径；本轮不新增展开或折弯写图路线。
- 曲面板、变厚/复杂空间实体及不能唯一确定的方向，不从曲边标志、包络或“平板证明失败”推定折弯，返回UNKNOWN/AMBIGUOUS并说明缺证。恒定非板状截面可报告PRISMATIC_SECTION，不推定轧制规格。
- 有RAW时先使用完整几何；不得以ContourPlate类型或PL名称覆盖冲突。无可用RAW/板边几何时拒绝进入平板专用证明。

## 实施与验收计划

1. 将已存在的通用挤出壳核验移到独立底层，保持算法不变；新增通用事实和纯事实分类模块，接入原生几何入口。
2. 表达报告和批次阻断保留类型及具体门阶段；非平直类型不运行平直板专用核验，缺证与类型未支持分开。
3. 回归相同形状不同建模命令、刚体变换、平面L轮廓与空间折弯的区别、等厚折线/变厚截面、缺面/曲边缺证、坡口仍为平直板。回放七件、当前坡口槽孔件及历史非共面件；完整回归、文档引用和diff检查。

本轮不写现场图纸；历史现场输入用于回放，不能称作新的Tekla实测。识别折弯类型不等于完成折弯出图能力。
