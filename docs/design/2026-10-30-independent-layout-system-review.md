## 0. 摘要

**总体判断**：原方案架构方向正确，建议保留，不推翻。做得好的地方：

- 布局只管"放哪"，不管"标什么"，职责边界清晰。
- 候选、硬约束、软目标三层分离。
- 词典序评分加确定性，结果可复现。
- 失败必须结构化解释，不允许只报 `LAYOUT_OVERFLOW`。
- 回读是最终证据，离线成功不等于合格图。
- 旧实现保留作对照基线，不作后备。

**本轮评审新增确认的决策**（详见 §1）：

- 比例固定 1:1。
- 图幅可变：A1–A4 及标准加长幅面均可用，允许续页。
- 视图朝向由系统决定。
- 松弛阶梯只允许 R0–R2，不做孔表/坐标表等表达替换。
- 目标：准入范围内单张图纸自动出图率 100%。

**在这些决策下，100% 原则上可达，但不是自动成立**，依赖三个必须补齐的前提：

1. **R2 必须是"构造性完备"的**：在图纸无界的前提下，R2 总存在一个无需搜索的确定性可行布局，作为兜底（§2.4）。
2. **1:1 下超过最大图幅的零件必须靠续页**：续页不是可选项，而是完备性的组成部分，目前完全未设计（§3.4）。
3. **Tekla 侧能力要先验证**：自定义/加长图幅、各图幅模板、多页自有页登记、兜底原语的可控性（§3.5）。

**原方案需要修改的 5 个 P0 问题**（§4）：

1. 可渲染性验证放得太晚。
2. 位置模型有自相矛盾之处（层位置、部件原点、外层循环）。
3. 全硬约束叠加不变量，会让"无解"成为常态，缺少阶梯与候选池分级。
4. 无解归因粒度太粗，且没有与候选升级联动。
5. 回读闭环缺少收敛机制。

## 2. 100% 出图的设计

### 2.1 "100%"的定义

- **准入范围**：通过输入准入（`INPUT_BLOCKED` 不成立）且形态为平直板主视图的零件。折弯板、曲面板、折梁、展开图等继续阻断，由确定性的准入规则给出，不计入出图率分母，但准入率单独统计。
- **出图**：返回一个通过全部硬验证（要求覆盖、文字/尺寸/界线/引线无非法冲突、同列与层序、孔组语义、模板与图幅边界）的 `LayoutPlan`，并能写入 Tekla 且回读一致，无需人工介入。
- **完备性**：准入范围内，系统不得以 `INFEASIBLE_CANDIDATES`、`SEARCH_LIMIT` 作为终态返回。出现即视为缺陷，与崩溃同级。
- **口径提醒**：100% 是完备性，不是"所有图都同样好看"。质量差异由档位（R0/R1/R2）和软目标体现，并记录在计划里。

### 2.2 失败源与对策

| 编号 | 失败源 | 在新决策下 | 对策 |
|---|---|---|---|
| F1 | 纸面空间不足 | 图幅可变后基本消除；但超过最大可用图幅的零件仍有 | 图幅装箱选择（§3.2）；超大件续页（§3.4） |
| F2 | 与图幅无关的局部无解 | 仍存在：零件号放不进材料内；孔组被其他孔围住，引线出不去；极窄间距的短尺寸链 | R1/R2 规则覆盖；R2 构造性兜底（§2.4） |
| F3 | Tekla 不可渲染 | 仍存在：Tekla 自动重排文字、缩短界线占用不确定 | 能力矩阵 + 占用标定前移；兜底只用"可控"原语；`RENDERABILITY_BLOCKED` 触发降档重解 |
| F4 | 输入不满足准入 | 与布局无关 | 单独统计；明确是否计入 100% 分母（建议不计入，但必须有清单与原因） |
| F5 | 模板/资源缺失 | 新增：各图幅是否有模板、自有页能否登记 | Tekla 能力验证（§3.5） |
| F6 | 求解超时 | 与完备性冲突 | 超时不是终态；超时则直接降档，最终落到 R2-C（构造法，无搜索，无超时风险） |

### 2.3 松弛阶梯 R0–R2

**阶梯是什么**：把"规则放宽"预先排成有序档位。先按最严格的 R0 求解，无解才降到 R1，再无解降到 R2。每一档放宽什么，是事先写死并经工程确认的，不由求解器临场决定。计划里记录实际使用的档位。

**与"候选池升级"的区别**：

- 候选池升级：规则不变，只增加候选（跨区候选、两段引线、路由生成候选），且只对冲突核心里的对象展开。
- 阶梯：规则本身放宽。

求解顺序：同一档位内先用小候选池，不行再升级候选池，仍不行才降档。

建议的档位内容（需工程确认；数值为示例，可调）：

| 档 | 放宽内容 | 层数上限（示例） | 可读性代价 |
|---|---|---|---|
| R0 | 原方案 §5.4 全部硬约束 | 每侧 ≤ 3 层 | 无 |
| R1 | 层间距可压至最小间距；尺寸界线可穿过其他尺寸线（仍不穿文字、不穿孔轮廓） | 每侧 ≤ 4 层 | 很小 |
| R2 | ① 短尺寸文字外置并交错；② 孔说明/半径引线允许两段折线，可穿越同组孔间空隙（不穿文字、不穿其他孔组孔轮廓）；③ 零件号材料内无空白时允许外置加引线；④ 界线可穿越孔轮廓（仅 R2，需工程确认） | 不设上限 | 小到中 |

**层数上限的意义**：图纸近似无界时，R0 可以靠堆叠层数"通过"，得到一张有 8 层尺寸链的无意义图。层数上限和包络惩罚防止这种退化；超过上限就降档。

**优先级策略（建议）**：先档位，后图幅。但对 R0/R1 设一个"图幅升级上限 K"：所需图幅比"能容纳零件本体的最小图幅"大超过 K 级时，该档位视为不满足，降档。默认 K = 1（可调）。K 是质量与图幅大小之间最关键的调节旋钮，需要工程确认。

### 2.4 R2-C：构造性兜底

R2-C 是 R2 规则下的**确定性构造算法**，不做搜索，在图纸无界时总是给出合格布局。它同时作为：

- 完备性的保证；
- CP-SAT 的温启动解；
- 求解超时时的最终兜底。

**构造思路**（这是论证草图，设计阶段需形式化，并用模糊测试验证）：

1. 每个轴向、每个侧别，尺寸链按层序向外堆叠，总体尺寸最外；层数不设上限。
2. 链内每个尺寸的文字：放得下就在线内，沿轴滑动以避开其他界线；放不下就外置到专属行，行数不设上限。
3. 尺寸界线允许穿越除文字外的任何对象（R2 ④）。因此尺寸链的放置只受"法向堆叠"限制，必然可行。
4. 孔说明与半径说明：在自由空间（材料区减孔、减保留带）里，用可见图或三角剖分求从所属孔近侧边界到板外的折线。终点文字沿板外按拓扑顺序排布，避免引线互相交叉。
5. 零件号：材料内有足够空白则放材料内；否则外置加引线。

**必须在设计阶段回答的两个问题**：

- 步骤 4 的"引线互不交叉"是否对任意准入零件成立？需要形式化论证；若出现反例（例如孔间零间隙），反例要触发规则补充流程（如允许共享干线）。
- 步骤 3 中"界线穿越孔轮廓"是否被车间接受？这是 R2 内部最敏感的一条，需要工程确认。

### 2.5 验证 100% 的方法

- **构造性论证**：为 R2-C 写出前提条件与可行性论证，作为设计文档的一部分。
- **模糊测试**：随机生成多边形外轮廓、不同数量和排布的孔、孔群包围、窄间距孔排，断言系统总能返回通过独立验证器的计划。测试集要包含"小板多孔"（零件号放不下）、"孔群包围"（引线出不去）、"极窄间距"三类对抗样例。
- **失败即缺陷**：准入范围内任何非成功终态都自动生成缺陷记录，附最小复现输入。
- **历史集回放**：历史 12 件样例（305、584、225、101、618、111、73、451、450、102 等）全部产出计划。

### 2.6 当前不能承诺 100% 的范围

在以下能力补齐前，对外声明的 100% 必须限定范围，并在准入规则里显式排除：

- 超过最大可用图幅的零件（续页能力上线前）。
- 没有模板的图幅（加长幅面）。
- 兜底原语未通过 Tekla 可控性验证的情形。

## 3. 图幅、朝向与续页

### 3.1 1:1 带来的结构性简化：两阶段求解

比例固定 1:1 后，纸面尺寸等于模型尺寸，布局对图幅的依赖大大降低。建议拆成两阶段：

- **阶段 A（无界平面求解）**：在以部件为原点的相对坐标系里求解，目标含"包络最小化"。此阶段只关心部件与标注之间的关系，不涉及图幅。
- **阶段 B（图幅装箱）**：给定阶段 A 的包络，选最小的可容纳图幅，并在可用区内放置。

这样原方案提出的"部件原点作为 CP-SAT 决策变量"可以取消，位置问题退化为装箱。

**前提假设**：模板固定对象（标题栏、表格）位于可用区之外，或可用区可以用若干矩形精确描述。若标题栏位于图框内部角落、可用区呈 L 形，则阶段 B 对每个图幅枚举若干放置点（居中、四角贴边）做精确检查。

**含义**：包络大小直接决定图幅，因此原方案 §5.5 中被推迟的"纸面包络"目标必须提前，并与层数惩罚一起提到软目标前列。

### 3.2 图幅候选与选择

- 图幅候选集合写入配置，按面积升序排列：A4、A3、A2、A1（A0 待确认）、标准加长幅面。横竖图纸分别作为候选。
- 每个图幅需要独立的 `TemplateSnapshot`（图框、标题栏、可用区、固定对象）。没有快照的图幅不进入候选。
- 搜索顺序（伪代码）：

```
for 档位 in [R0, R1, R2]:
    plans = []
    for 朝向 in [0°, 90°]:
        for 池 in [0, 1, 2]:                 # 仅对冲突核心内对象展开
            p = solve_unbounded(朝向, 档位, 池)
            if p.feasible: break
        if p.feasible:
            plans.append(fit_sheet(p))       # 装箱选图幅，受 K 约束
    if plans: return best(plans)             # 比较：图幅序 → 朝向偏好 → 软代价
return R2C_construct()                        # 构造性兜底；若超出最大图幅则进入续页
```

- 先用下界剪枝：零件本体加最小尺寸带的包络若已超过某图幅可用区，直接跳过该图幅。
- 同一 (朝向, 档位) 下，图幅选择近似单调（面积越大越容易），可用二分，但横竖不可比的图幅要分别处理。

### 3.3 朝向与文字方向规则

- 朝向优先：长边沿图纸长边。若旋转 90° 可使图幅降一级，则取旋转。
- 文字方向：作为硬约束，遵循制图习惯，文字从图纸底部或右侧可读。
- 朝向、图幅横竖均由系统确定，写入计划，不由上游传入。

### 3.4 续页表达（需要专项设计）

**为什么是必需的**：1:1 下，板长超过最大可用图幅时没有别的办法；而 100% 要求不允许把它们长期阻断。

**这里按"视图分段续页"理解。如果你说的续页含义不同（例如仅内容续页），请告知。**

设计原则（草案）：

- **触发条件**：零件本体加最小尺寸带的包络，超过所有允许图幅的最大可用区。
- **切分线**：沿长轴方向垂直切分。切分位置避开孔、圆弧、轮廓拐点的保护带，保证每页内要素完整；文字、引线、尺寸线不能跨切分线。
- **接续标记**：每条切分线标注接续符号和自基准端起的累计坐标，使任何要素的位置可推导。
- **每页独立求解**：每页是一份独立的 `LayoutInput`，其"必需要求"是归属本页的子集，复用同一求解器。
- **跨切分线的尺寸**：拆成两段，各自止于切分线，累计值之和必须等于原值。这需要尺寸方案模块提供拆分，且覆盖检查器要认可"拆分等于覆盖"。
- **总体尺寸**：首页（或每页）以总长标注；每页保留累计坐标。
- **页数上限与所有权**：需要定义页数上限，以及多页自有图纸的登记与写入授权。
- **备选**：长等截面板可评估折断视图，但这属于另一类表达，需要另行评审，不在本阶段。

**建议的先决动作**：先统计历史零件中，包络超过最大可用图幅的比例。若极少，可先把它们作为明确的"超大件"分支，但在 100% 声明里必须显式排除，直到续页上线。

### 3.5 需要在 Tekla 2017 验证的能力

- 程序化创建任意尺寸或标准加长图幅的图纸，标题栏与图框是否随之正确缩放。
- 每种候选图幅是否有可用模板，模板属性是否可读。
- 多页自有图纸的登记、命名、页号与所有权标记。
- 兜底原语（外置文字、两段引线、零件号外置）在 Tekla 2017 的位置可控性、保存重开后的稳定性。

## 4. 对原方案的修改建议

### P0：定稿前必须修改

**1. 可渲染性验证前移到阶段 0（§7 阶段 0、§9）**

原方案 §4.2 要求候选必须可渲染，但验证放在阶段 4。候选词汇表（短尺寸外置文字、缩短界线、两段引线、半径文字位置、文字旋转）取决于 Tekla 2017 的可控性。若不前移，阶段 1–3 可能建立在一个"离线好看、写不出来"的候选空间上。

建议阶段 0 增加三项正式交付：

- **渲染能力矩阵**：对每种原语逐项验证位置是否可指定、保存重开后是否保持、回读能否取到，结论分可控、部分可控、不可控。不可控的原语不进入候选词汇表。
- **占用标定**：用标定图，按文字长度 × 字高写入一批尺寸，从 DXF 读回真实文字外包框，拟合 `CalibrationProfile.v1`（文字宽度模型、偏置、误差分布 p50/p99/max）。候选占用框 = 估计框 + p99 安全边距，并记录来源和版本。
- **纵向切片**：用 305 给一个朴素布局，走通"写图→保存重开→读回→验证"全链路。

**2. 位置模型的三处缺陷（§5.2、§5.6、§3.5）**

- **部件原点**：原方案没定义谁决定部件在纸面上的位置。在新决策下，由 §3.1 的两阶段方案解决，无需原点决策变量。
- **层位置前后不一致**：5.2 的层是离散基线，5.6 又允许压缩层间距，离散阶段判可行与微调阶段不一致。建议层厚度由层内最大文字高度加间距推出，不用常数；离散阶段用保守（未压缩）几何；R1 的"层间距压至最小"作为一档升级。原则做法是每侧用区间变量加 NoOverlap 建模法向堆叠。
- **外层循环**：比例循环已取消；朝向与图幅循环按 §3.2 补充。

**3. 全硬约束加不变量，无解将成为常态（§5.4、§7 阶段 2）**

- 引入 R0–R2 阶梯与候选池分级（§2.3）。
- 阶段 2 的验收不能只是"6 个失败件能报告最小冲突对象"，要改为"完备性 100% 加兜底构造论证"。
- 可选：对"覆盖等价"的表达形式（链式、基准式、对称式）建模为 OR 组，每组选一个，并用软代价偏好链式。这是可选优化，不是完备性必需，且不涉及表格式表达。

**4. 无解归因三层化，并与候选升级联动（§4.3、§5.5）**

| 层 | 含义 | 处理 |
|---|---|---|
| `NO_CANDIDATE` | 生成器对该对象没有任何候选 | 报能力缺口 |
| `STATIC_BLOCKED` | 候选全被静态几何或模板挡死 | 报被谁挡 |
| `MUTUAL_CONFLICT` | 对象之间互相挤占 | 求冲突核心 |

冲突核心做法：给每个对象加 assumption literal，用 CP-SAT 的 `SufficientAssumptionsForInfeasibility()` 取核心（不保证最小），再用删除过滤收缩，并设预算。核心映射回对象，同时触发候选池升级，只对核心内对象展开下一级候选。

在完备系统里，这套归因主要用于解释"为什么在 R0 无解、被迫降档"和调试缺陷，不再作为对外终态。

**5. 回读闭环要有收敛机制（§5.8）**

- 回读发现的真实冲突，直接变成 nogood（这两个候选不能同选），或把该候选占用框替换为实测框。
- 最多 2 轮；仍不一致则 `RENDERABILITY_BLOCKED`，并触发降档重解，差异写回标定数据。
- R2-C 只使用"可控"原语，作为回读失败的最后落点。

### P1：求解与建模细节

**6. 词典序目标的实现（§5.5）**

- 第 1–2 层是硬约束，真正需要优化的是第 3 层之后；用可证明占优的整数权重（后一层上界加 1 作为前一层权重）合成单目标，一次求解，不要多次顺序求解。
- 坐标和代价统一缩放为整数（建议 0.01 mm）。
- 设相对 gap 上限和确定性时间上限，避免预算花在证明微小差异上。
- 确定性：`num_workers=1`（旧版本为 `num_search_workers`）最稳；若用多线程，用 `max_deterministic_time` 并实测"同输入多次结果一致"。固定 OR-Tools 版本，并写入计划。

**7. 软代价只对静态几何一元化**

"跨越无关孔/轮廓次数"是候选的一元属性，可预计算。动态对动态的交叉（引线×引线、引线×别的尺寸线）是成对属性，线性化后让模型变大；已定为硬冲突就不要再加软惩罚。

**8. 控制模型规模**

- 候选支配剪枝：同一对象内，若 A 的冲突集包含 B 的冲突集，且 A 代价不低于 B，且两者在组关系上无差别，则删 A。
- 对冲突图做连通分量分解，各分量独立求解，也让失败归因是局部的。
- 同一空间格子或同一线段上的互斥用 `AddAtMostOne` 团，不要逐对加不等式。

**9. `columnGroup` 的组合爆炸（§5.3）**

"整组一次生成"若按 侧 × 层 × 每个成员的文字策略做笛卡尔积，数量会爆炸。建议：

- 拆成组级变量 `g[side, layer]` 和成员级变量 `t[member, strategy]`，用蕴含连接。
- 链内只有相邻成员文字互斥，可用小 DP 预先算出每个组配置下的 Pareto 前沿（通常几个）作为组候选。
- 相邻短尺寸文字上下交错外置，要作为候选词汇（R2 ①）。

**10. 连续微调用约束图压实，不用坐标下降（§5.6）**

- 同一轴向的分离约束构成有向无环图，求最长路径即得最小包络，无路径依赖；剩余松弛再按偏好位置分配。
- 引线折点和非轴对齐部分用第二阶段 CP-SAT：整数偏移变量、线性差分约束，目标是偏离偏好位置的 L1 距离。
- 这样用不到 libvpsc，也不需要 LGPL 评估。
- "文字沿轴平移的安全区间"必须对已选邻居实算，不能沿用候选生成时的区间。

### P2：验收与测试

**11. 量化验收，扩大样本（§7、§8）**

- 把已有的人工标注零件图（DXF）抽取成与 `LayoutPlan` 相同的 schema，作为对照集，不用手工逐张录入。
- **规则相容性测试**：人工认可的图如果被规则判为硬违规，说明规则过严或标定有偏差。这是最便宜、信息量最大的检查。
- **A/B 偏好集**：对同一零件造 20–30 对不同布局，只标"哪个更好"，每对几秒钟。用它校准软目标排序，一致率门槛建议 ≥ 90%（可调）。比逐张精标省事得多。

**12. 验证器独立（§5.8）**

验证器输入是通用纸面图元（DXF 与回读都能转），与候选生成不共享碰撞代码，避免同源错误。同一个验证器同时用于离线计划、Tekla 回读和人工标注图。

**13. 预言机与元测试**

- 保留的纯 Python 穷举，升级成测试预言机：小规模实例上，CP-SAT 的最优值必须与穷举一致。
- 元测试：整体平移部件，结果应等价；镜像部件，代价应一致（仅 tie-break 不同）。

### P3：零碎但会咬人的点

- **digest 稳定性**：坐标用整数单位序列化，JSON 键排序固定，浮点不直接进 digest。Shapely 的 touch 与 intersect 语义统一，并设固定容差。
- **环境 spike 提前**：OR-Tools 与 Shapely 在 Tekla 2017 目标环境的安装与打包，放阶段 0 验证（半天即可）。
- **文档歧义**：
  - §5.1 的优先级字段在严格模式下无作用，应写明用于松弛顺序和报告排序。
  - "参考对象"是可选的，需要 `AtMostOne` 加奖励，原文未写。
  - §5.2 的区域先验若直接剪候选，就是隐藏的硬约束。剪掉的候选要进"备用池"并记录原因码，供升级使用。
- **人工 pin 与稳定性**：工程师手调一个说明后，其余对象应能围绕它重解（CP-SAT 里就是 `x[c] = 1`）。已确认的 305、584、225 可直接作为 pin 做回归。后续再加"与上一版计划的偏离"软项，避免模型小改造成整张图重排。
- **性能预算**：写明单件求解目标（P95）和 Tekla 往返预算，否则无法判断搜索预算是否合理。

### 对 `LayoutPlan` 字段的补充（§4.3）

建议新增字段：`ladderRung`（R0/R1/R2/R2C）、`candidatePool`、`orientation`、`sheet`（尺寸、横竖、是否加长）、`pages[]`（续页时）、`scale`（固定为 1）、`completeness`（是否由构造性兜底给出）。失败状态保留 `INPUT_BLOCKED`；`INFEASIBLE_CANDIDATES`、`SEARCH_LIMIT` 在准入范围内仅作为缺陷标记，不对外作为终态。

|---|---|---|

| 2 | 硬约束求解器 | **先实现 R2-C 构造性兜底**，使系统从第一天起完备；再实现 CP-SAT 的 R0、R1、R2 与池升级；两阶段求解（无界求解加图幅装箱）；三层归因；验收改为完备性 100% 加模糊测试 |

## 6. 建议的验收标准

| 指标 | 建议门槛 |
|---|---|
| 完备性 | 准入范围内历史集与模糊集 100% 产出通过独立验证器的计划；任何非成功终态视为缺陷 |
| 硬违规 | 0 |
| 档位分布 | 统计 R0/R1/R2/R2C 占比，作为持续优化目标（具体目标值待定） |
| 对人工图的规则相容 | 人工认可的图判为硬违规的比例趋近 0（出现则逐条定位原因） |
| A/B 一致率 | ≥ 90%（可调） |
| 确定性 | 同输入多次运行，计划与 digest 完全一致 |
| 回读一致 | 实测位置与计划偏差落在标定 p99 内 |
| 求解耗时 | P95 目标值待定 |
| 准入率 | 单列统计，附被阻断零件清单与原因 |

## 7. 待确认事项

1. A0 是否可用；标准加长幅面的具体清单，及 Tekla 2017 模板是否支持。
2. "续页"的含义：是否按"视图分段"理解；页数上限；多页自有图纸的登记规则。
3. 档位 R1、R2 每条放宽规则是否获得工程认可，尤其"界线穿越孔轮廓""零件号外置加引线"。
4. 图幅升级上限 K 与层数上限的取值。
5. `INPUT_BLOCKED` 零件是否计入 100% 分母（建议不计入，但需有清单与原因）。
6. 尺寸方案模块能否提供续页所需的"跨切分线尺寸拆分"，且覆盖检查器认可拆分覆盖。
7. 长等截面板是否评估折断视图作为续页的替代。
