# 实际穿透与逐件特殊孔归属

用户明确：一个螺栓组穿过多块板是正常连接，不能以关联板数阻断。失败归因是逐板孔形证据缺失，不是连接类型不支持。

## 分层修改

1. 几何层保留目标关联，并按真实螺栓实体的轴向范围与已经核验的目标板厚两面判断贯穿；孔心及完整孔边界必须位于已证明材料范围内。不设置两板/三板数量限制，不用 OtherParts 的列表顺序推定孔标志。
2. 孔形层可消费本次精确编号 NC：导出前后模型字段一致、编号有效、文件摘要/日志/编号匹配，非展开坐标，外轮廓与厚度先确定坐标对应，全部孔逐个唯一对应模型候选。孔数、位置、直径、槽长、方向必须全部吻合。NC 只补逐板孔形，不代替实际穿透或完整三维加工证明。
3. NC 的已识别外轮廓坡口字段不作为孔形来源，也不使已解析 BO 孔失效；其他未解释 NC 字段/块继续拒绝。坡口仍由独立三维终态核验。记录“NC 坡口字段未用于孔证明”与实际配置绑定尚未验证，不宣称 NC 生产放行。
4. 正式入口增加显式 NC 设置文件参数，在需要本次 NC 证据时导出到新目录，核对其原始零件与即时读取完全一致，再进入现有表达/计划/写图/保存重开流程。无 NC 的已验收路径保持兼容。

现场布局发现的单位问题：模板字号25被误用于孔中心线伸出量（2 mm变20 mm）。P5修正中心线按纸面2 mm/视图比例换算。编号优先保留原强调字号，仅模板模式没有静态安全位置时回退到模板正常字号（名义3→2.5，当前30→25），不小于模板文字。仍要求板内编号、无引线和完整碰撞检查，不缩图或删文字。

剖切标记从材料边缘向外检查16个有限位置，避开文字、尺寸基线、轮廓与引线，不再从整个标注包络额外扩大。原生标记显式采用模板字高和两端名称，保存后需在实际DXF确认两端文字存在。

现场live-02显示原生引线文字的SDK外框比Arial离线框左右各宽约0.4字高，DXF字形底部也超出约0.1字高。引线文字在原字体度量框外左右各留0.5字高、上下各留0.1字高，用于候选碰撞和图幅分配；这是有限样例下的保守规划，保存读回仍是最终验收，不能扩大验收容差求通过。普通无引线文字维持原框。

解析曲线视图不再把目标Part隐藏：隐藏会使Tekla材料表失去数据行。保留目标参与表格计算，仅把原生可见/隐藏线设Invisible并关闭填充、中心线等重复渲染。保存重开核对这些属性及模板内容签名，不放宽模板一致性门。
