# 内部独立特征孔旁标注优先

## 失败与口径

102 首张新页把中间孔定位尺寸统一拉到板端，用户否决。修正页已经回孔旁，但实现以 `localAllowed && len(band)==1` 判定，只覆盖孔带；矩形内口没有 band。用户进一步明确：内部独立孔旁标注是第一优先级，适用于圆孔、长圆孔、矩形孔、带倒角的矩形孔等，不能作为普通评分偏好。

## 共同规划规则

1. 从已审计事实中的孔中心身份或内闭合轮廓身份确定尺寸归属，不按零件号、孔形名称或 localAllowed 开关决定优先级。单个内部特征的定位及自身尺寸归属该特征；多孔共用链和整板总体尺寸保持原责任，不强行拆散。
2. 共同策略返回真实 featureId 和实际几何包围范围。内口由其真实线/弧构成，不把包围框角点用作测量锚点。已有 cutoutEvidence 必须指向同一内轮廓，外轮廓、其他孔的证据不得冒用。
3. 对这些独立特征，仅生成孔旁候选，换侧、移层、缩短显示界线和联合避让仍保留真实测量锚点。普通成本只比较孔旁方案，远端方案不进入同池竞争。孔旁是靠近孔边，不要求文字塞进孔内。
4. 当前试验沿用两个局部层与字号关联距离预算；回读检查到特征横向包围范围的距离不超过八倍字高。该数值只是有限试验能力边界，不是加工标准。候选无解或超时仍阻断，不宣称全域无解，不自动远端降级。

## 实施边界与验证

新共同策略由现有 r4 候选和回读直接调用；r1/r2/r3 已封存表达摘要保持，不向旧表达强塞新字段。矩形/圆角矩形使用已有 r2 加工语义；倒角矩形仅在共同策略与候选层用真实内轮廓夹具验证，尚缺完整加工语义和原生整页路线，原准入阻断保持。

验收：102 原远端页仍拒绝、修正页通过局部规则；圆孔/槽孔/矩形/圆角/倒角矩形候选仅在各自特征附近；平移镜像、多个同形孔各自归属、错误轮廓绑定、低成本远端竞争均有回归。源几何和尺寸锚点不改，未接通孔形不冒充已完成现场出图。
