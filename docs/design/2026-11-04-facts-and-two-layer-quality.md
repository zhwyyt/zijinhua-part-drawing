# 几何事实、加工要求与两层图纸质检

日期：2026-11-04。状态：路线与实施规划，尚未实现新质检器。

## 本次方向

用户决定暂缓继续推进自动出图，先收集50份人工图纸，做好硬正确性和人工风格两层质检。第一步扩展几何事实与加工要求，范围不再限于平板。用户确认大部分图纸能配到对应Tekla模型和加工说明。

先按样本覆盖范围补齐事实与要求，再做独立验收，最后恢复生成器改进。这里的“完整”指每个纳入范围的特征都有明确事实、加工责任和缺证状态，不承诺一次覆盖所有零件。不把新增类型标签当成已支持该类型的几何、展开或出图。

本轮只调整设计与工作优先级。保留当前代码、现场图纸和失败证据；原生产入口及所有权边界不变。此前布局方案和修复待办暂缓，只有用于事实读取、样本采集和质检验证的工作进入当前主线。识别、配送及BOX工序图继续留在原仓库。

## 当前代码基础与缺口

| 已检查位置 | 可复用基础 | 本阶段需要补齐的边界 |
| --- | --- | --- |
| `native_facts.py` | 原始来源、读取状态、实体边面环和孔参数候选 | 原始目录不等于完整解析几何；存在UNKNOWN和未证明拓扑 |
| `geometric_types.py` | 通用形状事实、平板/等厚折线带/棱柱候选与缺证原因 | 折线形态不能证明折弯工艺、真实半径或展开；一般曲面证据仍不足 |
| `native_expressions.py`、`expression_requirements.py` | 平板加工表达、孔与轮廓责任、部分剖面要求；切割/制孔/公差/边缘处理规格入口 | 现有要求以平板为中心，须建立跨类型的要求清单与适用性；几何容差与制造公差分开 |
| `independent_layout/semantic_coverage.py` | 语义责任核对 | 复用尺寸方案构造逻辑，不能独立发现生成器与检查器共同漏掉的要求 |
| `independent_layout/complete_trial_readback.py` | 原生锚点、显示对象、两次重开和计划一致性核对 | 依赖表达适配器，且限定单视图；不能直接充当多类型独立硬质检 |
| `independent_layout/visible_strokes.py`及图页占用模块 | 实际笔画、字形、遮罩与模板障碍证据 | 可作为检查原语，需覆盖整页与各视图，并区分不可读和风格偏好 |

现有失败可直接作为初始反例：101/102完整链仍碰字；被否决的拆链页；450材料表超框；102历史远端孔定位；既有模板缺字。历史回读或测试通过不覆盖这些工程结论。

## 目标数据流与责任

模型及工艺原始证据 → 几何事实与加工要求 → 独立硬质检；人工图纸及人工评价 → 风格案例库 → 风格质检。两层均读取实际图纸观察，输出可追溯报告。

生成器以后消费同一套经过审核的事实与要求，但不能替质检器定义“应检查什么”。允许共用单位转换、基础几何等底层原语；硬质检不得调用布局/表达生成器重建答案后仅做相等比较。人工核定的要求清单、独立测量和故意造错样本用于发现共因错误。

### 几何事实

每项事实记录对象/特征标识、值、单位、坐标系、源文件及版本、原始定位、读取或推导方法、数值误差依据和证据状态。区分原始毛坯、加工后终态及展开态；不同状态的坐标和尺寸不能混用。型号或建模命令不能代替实体证据。

以下为待逐项验证的覆盖清单，不代表现有能力：

| 事实域 | 必须能够表达的内容 |
| --- | --- |
| 共通身份与拓扑 | 零件及修订、材质/规格来源、单位、局部轴与手性、实体连通性、面边环及归属、基准和终态 |
| 板与曲面 | 厚度及其变化、外内轮廓、直线/圆弧/其他曲线、平面/柱面/其他曲面参数、近似误差 |
| 孔槽与切口 | 目标零件、实际数量、位置/轴向、孔径/槽宽长、贯穿/盲孔/深度、沉孔沉头、开口与闭口、相交或截断关系 |
| 坡口与端部 | 所在边面、方向、角度、深度、钝边、侧别、倒角/圆角及终态截面 |
| 折弯与曲面成形 | 折弯线/轴、折向、角度约定、内外半径、各段长度、曲率、成形前后关联；空间折弯及扭转的缺证 |
| 型材、梁与折梁 | 真实截面、路径、端切/斜切、开槽、截面变化、沿路径的局部坐标及特征定位 |

单项状态区分已证实、缺失、矛盾、不适用、算法暂不支持。不适用需要适用性依据，空值不能默认“不存在”；近似事实必须携带误差，不能伪装成精确曲线。

### 加工要求

要求独立于布局对象，记录要求ID、关联事实/特征、内容、适用性、来源及修订、必须表达的信息、允许的表达方式、验收方法和缺证原因。至少覆盖：

- 成品轮廓及定位、孔槽尺寸/数量/深度/方向、基准与尺寸链、材质/规格/厚度、坡口和端部加工。
- 适用时的折弯方向/角度/半径、展开尺寸、加工余量、制造公差、表面/边缘处理、加工方法与技术说明。
- 主视图、辅助视图、剖面、局部详图、展开图分别承担哪些表达责任，以及多视图间的一致性。

从几何推导的事实、工艺文件明确要求、人工图上的表达选择分开保存。模型没有的公差、加工顺序、折弯补偿/K因子或中性层依据不能从外观补造。展开要求适用但依据不足时明确阻断该项。模型、工艺文件、人工图互相矛盾时保留全部来源，交工程复核，不静默选一个为真。人工图也可能有错误。

## 第一层：硬正确性质检

输入为冻结的事实与要求、实际原生对象/视图及实际显示证据。人工图若只有PDF/CAD/图片，按能获得的证据检查；无法确定的对象关联或数值不能用OCR猜测放行。

检查范围：

1. 来源身份、版本、单位、比例、坐标与视图变换一致；源数据读取完整且没有未解决冲突。
2. 实际几何与尺寸数值、测量锚点、方向、孔数孔形、侧别、材质与加工说明正确。区分投影尺寸、真长、弧长、角度及展开尺寸。
3. 每项适用的加工要求均有实际图纸证据；存在遗漏、多余误导表达、互相矛盾、错误孔/边绑定时报告具体对象。不能只数尺寸条数。
4. 视图/剖面/展开责任完整，多视图一致；满足已确认的工程表达约束，例如保留完整尺寸链。等价表达须经明确契约认可，不以与某张范图逐对象一致为准。
5. 实际可见文字、符号、引线和表格能够辨读且不裁切、不误指。遮挡数值、关键缺字及内容超框是硬问题；轻微外观差异按已确认适用范围处理。
6. 对本系统生成图再核对保存重开后的实际结果，禁止用计划包围框或内存对象替代持久化显示证据。

报告分别使用PASS、FAIL、UNKNOWN、NOT_APPLICABLE；必需项UNKNOWN不得汇总PASS。报告携带要求ID、事实源、图纸对象/区域、预期、观察、误差与失败归因。容差分为模型数值误差、显示舍入、制造公差和纸面可读性，各自有依据，不能混为一个阈值。风格得分不能抵消任何硬错误。

## 第二层：从人工图学习风格

首版采用经人工确认的案例检索、风格条目和可解释评分；50份不预设足够训练泛化模型。是否引入统计模型由样本质量和留出集结果决定。

学习视图选择习惯、尺寸基准与组织、标注侧和层级、孔组表达、局部定位、说明/编号摆放、留白及模板习惯。先识别适用类型、特征和工艺场景，再比较；不抄绝对坐标，不按零件号或项目名写规则，不将高频做法直接升级为硬约束。

每条风格结论给出支持样例、反例、适用条件、冲突偏好和人工确认状态。输出分项偏差、参照样例与修改建议；无匹配类型时返回待人工复核。用户已明确的完整链、孔旁定位等工程约束保留，不能被统计偏好推翻。

硬检查不通过时仍可展示风格诊断，但整图不合格。硬检查通过、风格通过也只表示本版本覆盖范围内通过；恢复生产放行前仍需用户工程验收。

## 50份样本采集与划分

每份资料包尽量含：人工原图（原生/CAD/PDF，保留可读整页）、对应零件和冻结模型读取、加工说明、修订日期、图纸比例/单位/模板、人工认可点及已知问题。多页图以完整零件图集为一个案例，不按页面重复计数；文件保存在本地资料目录，版本化清单记录样本ID、摘要与配对关系。

大部分可配对的样本承担事实与硬正确性核验；仅有图纸的样本可学风格及检查图内一致性，不能证明它与模型完全一致。无需等齐50份：先取约8—10份差异大的样本校准字段和标注口径，再补齐覆盖缺口。

选样优先覆盖复杂度与失败模式，避免50份都是同类平板：简单基准件、复杂孔槽/内口、坡口及剖面、折弯板、曲面板、型材/折梁、多视图/展开。具体数量在样本盘点后确定，不为凑比例伪造缺失类型。留少量简单件作基准，保留人工确认的坏图和现有失败页作反例，不能把坏图混为风格正例。

建议按零件族划分30份学习、10份调校、10份封存验收，具体数量随实际重复族调整。近重复形状、同件修订及其变体进入同一组；先分组再归纳规则，防止看过答案。留出集一旦用于调规则就要重新建立封存集。没有覆盖的类型明确列为未验证域。

标注至少包括“事实—要求—实际图纸对象/区域”的对应、正误判定及理由、认可/不认可的风格。争议由用户工程复核；图纸文件齐全不等于标注完成。

## 实施顺序与验收

| 阶段 | 交付物 | 验收条件 |
| --- | --- | --- |
| 0：样本与事实盘点 | 首批配对样本清单、按特征的能力/缺口矩阵、事实及加工要求契约 | 每个必需字段都有来源或明确缺证，未知工艺不推定；首批人工确认覆盖清单 |
| 1：事实与要求扩展 | 按缺口补读取/解析/专用证明及加工责任；先完成首批类型，再扩至其余样本 | 已声明支持的特征与独立核定数据一致；缺失、矛盾、相似形状不同工艺均能正确阻断/区分 |
| 2：硬质检 | 从事实、要求和实际图面出发的独立报告 | 正例不误判；错数、漏标、错孔、镜像/方向错误、漏剖面、工艺缺失、碰字及超框的植错案例均检出，未知不通过 |
| 3：风格质检 | 经确认的风格案例库、适用性及分项解释 | 在封存样本上与人工判断对照；逐类报告分歧、误报、漏报和不确定项，不仅给平均分 |
| 4：恢复出图 | 用两层质检驱动生成器修复的后续计划 | 固定验收集无已知硬错误漏放，支持域及未验证域公开，风格分歧经用户裁定后再决定恢复范围 |

各阶段规则变更必须留下失败样本、期望口径、证据字段和回归。测试包含刚体变换、单位/视图比例变化、镜像手性、近似与缺证等有意义的变体；镜像不能抹掉加工侧别。报告分别列出覆盖分母、通过/失败/未知、错误放行和误阻断；仅有单元测试总数不作为阶段完成证据。
