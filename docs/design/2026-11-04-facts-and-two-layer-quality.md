每轮四步：①首件探查：用户选3—5件同类型、特征不同的零件，只读采集并跑现有链路，报告能判定和缺少的内容，不改代码；②定口径：写该类型的事实清单、加工表达责任和缺证阻断方式，用户确认后才写代码；③实现与回归：补读取、事实和表达，用本轮真实数据做回归，加刚体/镜像等变体；④逐件解析：之后每选一件出一份解析卡，错误按失败归因处理并留回归。一轮至少3件，避免按单件写特例。

每件交付放在`outputs/part-facts/<日期>-<零件号>/`（不入库）：原始读取、事实、加工表达、简图PNG和中文解析卡。解析卡依次写零件身份、类型判定及依据、几何事实表、零件特征清单（孔、槽、切口、倒角、坡口、折弯等，各自的归属与定位）、加工表达清单、缺证与阻断项。简图供用户一眼核对轮廓、截面、展开及特征位置。

用户确认的类型口径：

- 折板是单个零件，可能用板命令（`BentPlate`）或梁命令（`PolyBeam`）建模；类型按几何判定，不按建模命令。Tekla 2017 SDK有`BentPlate`（`Geometry`/`Thickness`，求解器含半径和柱面接口）；当前读取器对`BentPlate`不读建模轮廓，只读实体，首轮探查补核。
- 折板需要展开图和展开尺寸。展开的计算口径（中性层位置、半径来源）待首轮探查后与用户确认；标注写法以后从人工图学习对标。
- 型材规格按profile名称。孔、倒角、坡口必须归属到具体腹板或翼缘，在该板件上定位，不针对整个型材。
- 用户选件时可附人工图截图，用于核对加工表达有没有漏项。

50份人工图纸仍是后续风格学习与对比的来源，不再作为阶段0开始前的盘点前置。

### 保持的不变量

- 目标是车间工人能准确、直接地读图；字号不缩、必需尺寸不删、模型不改。真实微小倾斜不得为了对齐被吸附成水平或垂直。
- 保留完整尺寸链、已确认的孔旁定位及工程表达约束；风格偏好不能覆盖硬条件。允许有依据的参考/总尺寸冗余，拒绝未经声明的重复。
- 布局接收“视图、标注对象及其语义约束”的类型无关输入，只调整已允许的位置或显示形式；类型专用规则留在事实/表达适配和候选策略中，不写进通用碰撞及求解核心。
- 旧`native_layout`/`construct_layout`保留为对照，不作为新路线失败后的自动兜底。正式入口替换另行验收，不随指标或实验完成自动发生。
- 模板与比例沿用已核验的10/20/50及既定候选范围。本规划不改图幅政策；实际来源与配置冲突时报告具体差异，解决前不写图。
- 固定准入验收集以100%合格为目标，同时公开总样本数、范围外及未知项；不通过事后缩小分母兑现目标。未知、能力不足、预算耗尽与已证明无解分开报告，不强行出图。

## 目标数据流与责任

模型原始证据 → 几何事实/专用核验 → 加工表达要求 → 独立硬质检；人工图纸用于核定表达覆盖及学习风格。硬质检核对事实、应表达内容与实际图面；风格质检核对人工表达习惯。两层均输出可追溯报告。

生成器以后消费同一套经过审核的事实与要求，但不能替质检器定义“应检查什么”。允许共用单位转换、基础几何等底层原语；硬质检不得调用布局/表达生成器重建答案后仅做相等比较。人工核定的要求清单、独立测量和故意造错样本用于发现共因错误。

### 共用指标与独立验收

保留Claude“同一把尺子”的核心：建立统一的风格指标定义与计算模块，质检报告和后续求解目标共用版本、单位及适用条件。求解时计算候选的预估指标，验收时计算实际图面的观测指标；两者差值单独报告。若CP-SAT必须采用离散化或近似代价，记录映射与误差，并用相同样本验证，不能用另一套未说明的评分替代。

硬检查可共用几何测量原语，但期望来自事实与加工表达，覆盖验证同时有独立核定样本及植错反例。不得让生成器和验收器共用“应有哪些尺寸”的构造函数后仅验证相等。风格结果按分项给出，尚未校准的权重不生成伪精确总分。

| --- | --- |

### 几何事实

每项事实记录对象/特征标识、值、单位、坐标系、源文件及版本、原始定位、读取或推导方法、数值误差依据和证据状态。区分原始毛坯、加工后终态及展开态；不同状态的坐标和尺寸不能混用。型号或建模命令不能代替实体证据。

以下为待逐项验证的覆盖清单，不代表现有能力：

| 事实域 | 必须能够表达的内容 |
| --- | --- |
| 共通身份与拓扑 | 零件及修订、材质/规格来源、单位、局部轴与手性、实体连通性、面边环及归属、基准和终态 |
| 板与曲面 | 厚度及其变化、外内轮廓、直线/圆弧/其他曲线、平面/柱面/其他曲面参数、近似误差 |
| 孔槽与切口 | 目标零件、实际数量、位置/轴向、孔径/槽宽长、贯穿/盲孔/深度、沉孔沉头、开口与闭口、相交或截断关系 |
| 坡口与端部 | 所在边面、方向、角度、深度、钝边、侧别、倒角/圆角及终态截面 |
| 折弯与曲面成形 | 折弯线/轴、折向、角度约定、内外半径、各段长度、曲率、成形前后关联；空间折弯及扭转的缺证 |
| 型材、梁与折梁 | 真实截面、路径、端切/斜切、开槽、截面变化、沿路径的局部坐标及特征定位 |

单项状态区分已证实、缺失、矛盾、不适用、算法暂不支持。不适用需要适用性依据，空值不能默认“不存在”；近似事实必须携带误差，不能伪装成精确曲线。

### 加工表达要求

沿用现有`expressionRequirements`的要求ID、feature、aspect、expected、rule、alternatives及剖面责任，扩展到新几何类型。要求独立于布局对象，说明每个特征必须表达的信息、允许的表达方式和覆盖核验依据。至少覆盖：

- 成品轮廓及定位、孔槽尺寸/数量/深度/方向、基准与尺寸链、材质/规格/厚度、坡口和端部加工。
- 新类型适用的折弯方向/角度/半径、各段定位、曲面形状、型材截面与端切；需要展开表达时明确其尺寸及与成形态的对应。
- 主视图、辅助视图、剖面、局部详图、展开图分别承担哪些表达责任，以及多视图间的一致性。

例如：读到一个长圆孔是几何事实；要求图上交代孔形、宽长、数量、定位和方向是加工表达；采用哪组尺寸及怎样排布由后续方案与布局负责。坡口事实应产生角度、深度、钝边、侧别及必要剖面的表达责任。加工表达完整性检查不能退化为尺寸条数检查。

模型事实、应表达内容、人工图实际采用的表达分开保存。人工图可能漏标或错标，要保留差异供核定。已有可选`specifications`入口继续保留，但外部工艺文件不是此次样本的必备资料，也不将工艺规划扩为本阶段主线。需要展开而现有事实不足时记录具体缺证，不推造展开尺寸。

## 第一层：硬正确性质检

输入为冻结的事实与要求、实际原生对象/视图及实际显示证据。人工图若只有PDF/CAD/图片，按能获得的证据检查；无法确定的对象关联或数值不能用OCR猜测放行。

检查范围：

1. 来源身份、版本、单位、比例、坐标与视图变换一致；源数据读取完整且没有未解决冲突。
2. 实际几何与尺寸数值、测量锚点、方向、孔数孔形、侧别、材质及图上说明正确。区分投影尺寸、真长、弧长、角度及展开尺寸。
3. 每项适用的加工表达要求均有实际图纸证据；存在遗漏、多余误导表达、互相矛盾、错误孔/边绑定时报告具体对象。不能只数尺寸条数。
4. 视图/剖面/展开责任完整，多视图一致；满足已确认的工程表达约束，例如保留完整尺寸链。等价表达须经明确契约认可，不以与某张范图逐对象一致为准。
5. 实际可见文字、符号、引线和表格能够辨读且不裁切、不误指。遮挡数值、关键缺字及内容超框是硬问题；轻微外观差异按已确认适用范围处理。
6. 对本系统生成图再核对保存重开后的实际结果，禁止用计划包围框或内存对象替代持久化显示证据。

碰撞按对象关系判断，区分合法端点接触、必要连接、允许交叉和遮挡/误指，不将所有线交叉直接判错。位置约束闭合是必要检查之一，不能代替轮廓、孔径/孔数、方向、坡口、剖面等表达责任，也不能代替已确认的直接读数要求。硬规则按工程口径和几何关系编写；人工图可提供反例与口径证据，不以出现频率学习“正确”。

报告分别使用PASS、FAIL、UNKNOWN、NOT_APPLICABLE；必需项UNKNOWN不得汇总PASS。报告携带要求ID、事实源、图纸对象/区域、预期、观察、误差与失败归因。容差分为模型数值误差、显示舍入、制造公差和纸面可读性，各自有依据，不能混为一个阈值。风格得分不能抵消任何硬错误。

## 第二层：从人工图学习风格

首版先实现指标计算，再通过人工/自动配对比较核定指标与偏好；案例归纳服务于指标解释和后续权重校准，不另起一个优先于指标对比的案例检索产品。50份不预设足够训练泛化模型，本阶段不以训练模型为前提。

学习视图选择习惯、尺寸基准与组织、标注侧和层级、孔组表达、局部定位、说明/编号摆放、留白及模板习惯。先识别适用类型、特征和工艺场景，再比较；不抄绝对坐标，不按零件号或项目名写规则，不将高频做法直接升级为硬约束。

每条风格结论给出支持样例、反例、适用条件、冲突偏好和人工确认状态。输出分项偏差、参照样例与修改建议；无匹配类型时返回待人工复核。用户已明确的完整链、孔旁定位等工程约束保留，不能被统计偏好推翻。

首轮指标按Claude意图落实为以下可测项。指标先给观察值，不提前把一种习惯写成所有图纸的最优解：

| 指标组 | 首轮观察量及边界 |
| --- | --- |
| 侧与层级 | 特征所属侧、尺寸层级、首层距轮廓距离、层距及离散程度；按相关特征组统计 |
| 对齐与顺序 | 同列/同层偏差、尺寸链顺序与空间顺序、相对跨度的内外层次；保留真实倾角 |
| 文字规律 | 居中/偏置/外置方式、相对尺寸线的位置、同角色一致性、实际可用文字空间 |
| 分布与关联 | 各侧数量、可用空间和特征分布、说明到所属特征距离；不把各侧数量相等当作目标 |
| 引线 | 长度、折点、方向、与无关对象的穿越；合法连接和造成歧义的穿越分开 |
| 表达组织 | 链式/基线式、基准与分组作为风格观察；布局不能因此自行重组尺寸方案 |

纸面距离优先按对应角色的有效字高归一化，同时保存原值、字高来源及原始单位；混合字号须明确参照角色。制造尺寸误差使用模型单位，角度使用角度，数量使用计数；模板空白和密度考虑可用面积。人工图的字高或尺度无法可靠读取时记UNKNOWN，不伪造归一化值。

硬检查不通过时仍可展示风格诊断，但整图不合格。硬检查通过、风格通过也只表示本版本覆盖范围内通过；恢复生产放行前仍需用户工程验收。

## 50份样本采集与划分

用户准备人工原图及能对应的Tekla模型零件即可。项目采集模型事实，整理“这个零件必须表达什么”及人工图如何覆盖这些要求；同时记录修订、比例/单位/模板和人工认可点及已知问题。无需另外准备加工说明文件。多页图以完整零件图集为一个案例，不按页面重复计数；文件保存在本地资料目录，版本化清单记录样本ID、摘要与配对关系。

大部分可配对的样本承担事实与硬正确性核验；仅有图纸的样本可学风格及检查图内一致性，不能证明它与模型完全一致。无需等齐50份：先取约8—10份差异大的样本校准字段和标注口径，再补齐覆盖缺口。

选样优先覆盖复杂度与失败模式，避免50份都是同类平板：简单基准件、复杂孔槽/内口、坡口及剖面、折弯板、曲面板、型材/折梁、多视图/展开。具体数量在样本盘点后确定，不为凑比例伪造缺失类型。留少量简单件作基准，保留人工确认的坏图和现有失败页作反例，不能把坏图混为风格正例。

建议按零件族划分30份学习、10份调校、10份封存验收，具体数量随实际重复族调整。近重复形状、同件修订及其变体进入同一组；先分组再归纳规则，防止看过答案。留出集一旦用于调规则就要重新建立封存集。没有覆盖的类型明确列为未验证域。

首批8—10份用于覆盖盘点；阶段2的3—5组用于验证指标是否解释好坏；50份用于后续归纳、调校和留出验证，三者用途不同。阶段2从非封存样本中挑选，人工版/自动版必须对应相同几何修订及加工表达责任。缺少某版或表达内容不同则明确列出缺口，不能把漏标导致的清爽算成风格进步。全部人工图目录与实际配对关系仍待采集核验。

标注至少包括“事实—要求—实际图纸对象/区域”的对应、正误判定及理由、认可/不认可的风格。争议由用户工程复核；图纸文件齐全不等于标注完成。

## 实施顺序与验收

阶段0承接用户“先扩展事实和加工表达”的要求；阶段1—4保持Claude的指标、对比、候选、优化顺序。每阶段交付后停下，由用户确认再进入下一阶段，不预支后续实现。本轮只形成规划；尚未启动阶段0的数据采集或代码实施。

| 阶段 | 交付物与范围 | 验收及进入下一阶段的条件 |
| --- | --- | --- |
| 0：事实与加工表达准备 | 按类型逐轮（折板→直型材→折梁→曲面板）：首件探查、类型口径、事实/表达实现、逐件解析卡与简图；按缺口扩展读取、专用证明及表达责任，不扩展出图路线 | 首批声明支持的特征有独立核定事实及完整表达责任；缺失/矛盾正确阻断，其他域明确未支持；报告后等用户确认 |
| 1：两层指标模块 | 同时实现硬检查与风格指标计算，给出对象级报告；复用可验证原语，不改候选或求解器 | 硬检查通过正例/植错反例验证；风格测量有手工核对值、适用性及单位/比例变体；此时不宣称指标已能判断人工好坏；报告后等确认 |
| 2：3—5组对比实验 | 同件同表达的人工好版和自动差版，同一版本指标计算分项差异表、图面定位和人工分歧；不改求解器 | 能解释用户指出的问题，不能解释的明确补测/修订指标，不盲调权重制造排序；用户审阅对比结果后才决定阶段3 |
| 3：结构化候选 | 在已冻结标注对象上构造“选边 × 选层级 × 文字槽位”；按对比证据补候选及必要显示形式，不改标什么 | 候选保持锚点、完整链、语义侧及工程约束；文字交错/箭头外置/折引线等逐项验证原生可实现性与保存后显示；未知能力不作兜底；报告后等确认 |
| 4：目标校准与回读闭环 | 共用风格指标校准软目标；验证合规规则解热启动、局部邻域修复和实际占用反馈重解的收益 | 同一候选条件下比较优化前后，公开分项收益与退化；留出集验证、硬条件不退化；限定重解预算并保留失败；报告后另行决定生产接入 |

阶段3的链式/基线式切换如需改变标注方案，应返回表达/方案层单独评审，不藏入位置候选。已否决的拆链不因文字槽位调整而重新引入。阶段4热启动仅使用满足当前契约的解；原生反馈仅修正已证实的显示占用偏差，不改几何事实或删尺寸。有限候选无解不能宣称全域无解。

每阶段报告统一列出：本阶段改动及边界、输入版本和覆盖分母、验证命令/结果、硬错误与UNKNOWN、分项指标及对比、人工分歧、失败归因、下一步建议。阶段0没有风格指标时明确“不适用”，不能编造对比结果；阶段1区分测量验证和好坏排序验证。数据问题进质量门，缺特征补读取/事实，评分问题留回归，新类型补定义/样例/测试。

各阶段规则变更必须留下失败样本、期望口径、证据字段和回归。测试包含刚体变换、单位/视图比例变化、镜像手性、近似与缺证等有意义的变体；镜像不能抹掉加工侧别。报告分别列出覆盖分母、通过/失败/未知、错误放行和误阻断；仅有单元测试总数不作为阶段完成证据。
